<objective>
Create the three shared TypeScript packages — `@claw/shared-types`, `@claw/event-schemas`, and `@claw/tool-contracts` — as pure TypeScript packages using the internal packages strategy (no build step needed for type resolution). These packages provide the contract layer between all services.

Purpose: Every service in the monorepo needs to agree on the shape of domain entities, event payloads, and tool request/response contracts. Defining these once in shared packages prevents type drift and ensures runtime validation (via Zod) catches contract violations at service boundaries.

Output: Three compilable packages with full TypeScript types and Zod v4 runtime validation schemas that any workspace can import via `@claw/shared-types`, `@claw/event-schemas`, or `@claw/tool-contracts`.
</objective>
