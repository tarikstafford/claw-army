<objective>
Migrate the SvelteKit UI from adapter-static (SPA mode) to adapter-vercel (server runtime). This is a blocking prerequisite for Auth.js — hooks.server.ts, +page.server.ts, and +layout.server.ts cannot execute in a static SPA. The /new-execution auth gate and all other Auth.js server files depend on this plan completing first.

Purpose: Auth.js @auth/sveltekit requires a real server runtime. adapter-static produces a bare HTML shell where server files never execute. adapter-vercel enables Vercel serverless functions so hooks and server load functions run on every request.

Output: Updated svelte.config.js (adapter-vercel), updated vercel.json (no SPA fallback), updated +layout.js (no ssr=false), updated package.json (adapter-static removed, adapter-vercel installed).
</objective>
