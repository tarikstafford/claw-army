  <action>
Create 4 new schema files following the exact pattern established in existing files (bots.ts, dna-store.ts). Each file uses drizzle-orm/pg-core imports and exports its table + inferred types.

**bot-souls.ts:**
- Import `pgTable, uuid, text, varchar, integer, boolean, jsonb, timestamp, index, vector` from `drizzle-orm/pg-core`
- Define `botSouls` pgTable with columns:
  - `id` uuid PK defaultRandom
  - `isArchetype` boolean notNull default false
  - `archetypeName` varchar(100) nullable
  - `botId` uuid nullable (no FK — avoid circular ref with bots table)
  - `executionId` uuid nullable (no FK — avoid circular ref)
  - `taskCategory` varchar(255) nullable
  - `soulContent` text notNull
  - `contentHash` varchar(64) notNull (SHA-256 hex)
  - `generation` integer notNull default 1
  - `parentSoulId` uuid nullable — self-referencing FK using `references(() => botSouls.id)` with lazy arrow
  - `dimensions` jsonb notNull (the 7-dimension breakdown)
  - `constitutionDirectives` jsonb notNull (array of inviolable directives)
  - `embedding` vector('embedding', { dimensions: 1536 }) nullable — for Phase 9 cosine similarity
  - `createdAt` timestamp with timezone precision 3, notNull, defaultNow
- Add 5 indexes: is_archetype, bot_id, task_category, content_hash, parent_soul_id
- Export `BotSoul` ($inferSelect) and `NewBotSoul` ($inferInsert) types

**decision-traces.ts:**
- Import from `drizzle-orm/pg-core` and import `executions` from `./executions`
- Add JSDoc block documenting: "TTL POLICY: Records older than 90 days are eligible for archival. Archival is triggered before this table reaches 5,000,000 rows. Phase 8 documents this policy; Phase 10 implements the archival mechanism."
- Define `decisionTraces` pgTable with columns:
  - `id` uuid PK defaultRandom
  - `executionId` uuid notNull FK to executions.id cascade
  - `botId` uuid notNull
  - `soulId` uuid nullable (FK to botSouls using lazy arrow reference)
  - `decisionId` uuid notNull (caller-generated idempotency key)
  - `decisionType` varchar(50) notNull (tool_call | reasoning_branch | output_step)
  - `directiveReferenced` text nullable
  - `attributionConfidence` numeric(4,3) nullable (0.000-1.000)
  - `outcome` varchar(50) nullable (success | failure | partial)
  - `metadata` jsonb nullable
  - `decidedAt` timestamp tz precision 3 notNull
  - `createdAt` timestamp tz precision 3 notNull defaultNow
- Add 4 indexes: execution_id, bot_id, soul_id, decided_at
- Export `DecisionTrace` and `NewDecisionTrace` types

**council-verdicts.ts:**
- Import from `drizzle-orm/pg-core` and import `executions` from `./executions`
- Define `verdictTypeEnum` pgEnum with values: ['Promote', 'Maintain', 'Monitor', 'Demote', 'Retire']
- Define `verdictStatusEnum` pgEnum with values: ['pending', 'confirmed', 'rejected']
- Define `councilVerdicts` pgTable with columns:
  - `id` uuid PK defaultRandom
  - `executionId` uuid notNull FK executions cascade
  - `botId` uuid notNull
  - `soulId` uuid nullable
  - `verdictType` verdictTypeEnum notNull
  - `status` verdictStatusEnum notNull default 'pending'
  - `weightedConfidenceScore` numeric(4,3) notNull
  - `requiresHumanConfirmation` boolean notNull default false
  - `hasUnresolvedDevilsAdvocate` boolean notNull default false
  - `verdictSummary` text notNull
  - `performanceJudgeOutput` jsonb nullable
  - `soulAnalystOutput` jsonb nullable
  - `devilsAdvocateOutput` jsonb nullable
  - `confirmedAt` timestamp tz precision 3 nullable
  - `confirmedBy` varchar(255) nullable
  - `createdAt` timestamp tz precision 3 notNull defaultNow
  - `updatedAt` timestamp tz precision 3 notNull defaultNow
- Add 5 indexes: execution_id, bot_id, verdict_type, status, requires_human_confirmation
- Export `CouncilVerdict` and `NewCouncilVerdict` types

**negative-signal-register.ts:**
- Import from `drizzle-orm/pg-core`, import `botSouls` from `./bot-souls`, import `executions` from `./executions`
- Define `negativeSignalRegister` pgTable with columns:
  - `id` uuid PK defaultRandom
  - `soulId` uuid notNull FK to botSouls.id
  - `botId` uuid notNull
  - `executionId` uuid nullable FK to executions.id set null
  - `failureType` varchar(50) notNull
  - `directiveFailureSummary` text nullable
  - `mutationBlacklist` jsonb nullable
  - `registeredAt` timestamp tz precision 3 notNull defaultNow
- Add 3 indexes: soul_id, failure_type, registered_at
- Export `NegativeSignal` and `NewNegativeSignal` types

IMPORTANT: Do NOT import `vector` if your Drizzle version doesn't export it from the top-level `pg-core`. Check the research — drizzle-orm 0.45.1 DOES export it directly from `drizzle-orm/pg-core`.
