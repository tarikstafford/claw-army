    - Computes the next version number: `SELECT MAX(version) FROM dna_store WHERE objective_category = ? AND soul_id = ?` using `max()` from `drizzle-orm`. Uses the transaction `tx` for the query.
    - Inserts a new `dna_store` row with:
      - `botId`, `executionId`, `objectiveCategory` (= taskCategory), `soulId` from params
      - `version`: computed maxVersion + 1 (default 1 if no prior rows)
      - `compositeScore`: from params
      - `isProvisional`: set to `true` if `weightedConfidenceScore < GODL_CONFIDENCE_THRESHOLD` (export `GODL_CONFIDENCE_THRESHOLD = 0.50` as a named constant)
      - `parentSoulIds`: from params (uuid array — parent soul lineage)
      - `mutationLineage`: from params (JSONB — mutation operations applied)
      - `dnaPayload`: Full GODL-02 payload object containing all existing fields (systemPromptTemplate, toolCallSequence, etc.) PLUS the new fields (soulContent, taskCategory, agentClassAtWrite, compositeFitnessScore, fitnessDimensionBreakdown, causalAttributionSummary, councilVerdictSummary, councilConfidenceScores, humanConfirmationTimestamp, mutationLineageOps, isPioneerEntry)
    - Returns `{ version, isProvisional }`.

    **Function signature:**
    ```typescript
    import type { PgTransaction } from 'drizzle-orm/pg-core';

      soulId: string;
    ```

    - If NO rows exist (pioneer event):

      - Update maturity flags: `benchmarkMature = runCount >= 3`, `standardPromotion = runCount >= 3`, `thinDataFlag = runCount < 5`.

      - Return `{ isPioneer: false, benchmarkMature: updatedRunCount >= 3, baselineCompositeScore: existing.baselineCompositeScore }`.
