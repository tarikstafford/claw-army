  <name>Task 1: Extend leaderboard endpoint to join agent_classes and council_verdicts</name>
  <files>services/execution-service/src/routes/executions.ts</files>
  <action>
In the `GET /:id/leaderboard` route handler (around line 341-410 in executions.ts):

1. Add imports at the top of the file for `agentClasses` and `councilVerdicts` from `@claw/db`, and `inArray`, `desc` from `drizzle-orm` (if not already imported).

2. Extend the TypeBox response schema to include 4 new fields:
   - `agentClass: Type.Union([Type.Enum({ Novice: 'Novice', Understudy: 'Understudy', Artisan: 'Artisan', Retired: 'Retired' }), Type.Null()])`
   - `isPioneer: Type.Boolean()`
   - `verdictSummary: Type.Union([Type.String(), Type.Null()])`
   - `verdictType: Type.Union([Type.String(), Type.Null()])`

3. After the existing `botRows` query, add two batch queries:
   a. Query `agentClasses` for all bot IDs in the execution using `inArray(agentClasses.botId, botIds)` where `botIds = botRows.map(b => b.botId)`. Select `botId`, `currentClass`, `isPioneer`, `taskCategory`.
   b. Query `councilVerdicts` for all bot IDs in this execution using `inArray(councilVerdicts.botId, botIds)` AND `eq(councilVerdicts.executionId, id)`. Select `botId`, `verdictType`, `verdictSummary`, `createdAt`. Order by `desc(councilVerdicts.createdAt)`.

4. Build lookup maps:
   a. For agent classes: group rows by botId. For each bot, pick the highest-ranked class using rank order Artisan(3) > Understudy(2) > Novice(1) > Retired(0). If any row has `isPioneer = true`, set `isPioneer = true` for that bot.
   b. For verdicts: group rows by botId. Take the first (most recent by createdAt desc) verdict per bot.

5. Merge the new fields into the existing `leaderboard` response array. For each bot:
   - `agentClass`: from the highest-ranked agent class row, or `null` if no agent_classes row exists
   - `isPioneer`: `true` if any agent_classes row for this bot has `isPioneer = true`, else `false`
   - `verdictSummary`: from the most recent council_verdicts row, or `null`
   - `verdictType`: from the most recent council_verdicts row, or `null`

IMPORTANT: `bots.tier` (High/Medium/Low performance tier) is DIFFERENT from `agent_classes.currentClass` (Novice/Understudy/Artisan evolutionary class). Both must remain in the response — do NOT remove or replace `tier`.

Guard against empty botIds array: if `botRows.length === 0`, skip the agent_classes and council_verdicts queries entirely to avoid `inArray` with empty array (which throws in Drizzle).
