  <name>Task 1: Create objectives route file with all five endpoints</name>
  <files>

  <action>
    Create `services/execution-service/src/routes/objectives.ts` as a `FastifyPluginAsyncTypebox` plugin exporting `objectivesRoutes`. Follow the exact pattern from `executions.ts` and `billing.ts`.

    **Imports:**
    - `Type` from `@sinclair/typebox`
    - `FastifyPluginAsyncTypebox` from `@fastify/type-provider-typebox`
    - `verifyAuthToken` from `../lib/verify-auth-token.js`
    - `db`, `objectives`, `executions` from `@claw/db`
    - `eq`, `sql` from `drizzle-orm`

    **1. POST / (create objective, OBJ-01)**
    - Body schema: `{ name: String(minLength:1, maxLength:255), description: Optional(String()), defaultMaxBots: Integer(minimum:3, maximum:20), defaultBudgetCapCents: Optional(Integer(minimum:0)), defaultRuntimeLimitSeconds: Optional(Integer(minimum:60)), defaultAllowedTools: Optional(Array(String())) }`
    - Response 201: full objective object. Response 400: `{ error: string }`.
    - PreHandler: `verifyAuthToken` (same auth pattern as POST /executions)
    - Handler: Insert into objectives table with provided values. `defaultAllowedTools` defaults to `[]` if not provided. Return the created row using `.returning()`.

    **2. GET / (list objectives with aggregation, OBJ-03)**
    - No auth preHandler (matches GET /executions/all pattern)
    - Response 200: array of objective objects with 4 aggregation fields
    - Use correlated subqueries (same pattern as billing.ts):
      - `lastRunStatus`: `(SELECT e.status FROM executions e WHERE e.objective_id = objectives.id ORDER BY e.created_at DESC LIMIT 1)` typed as `string | null`
      - `runCount`: `(SELECT CAST(COUNT(*) AS int) FROM executions e WHERE e.objective_id = objectives.id)` typed as `number`
      - `totalSpendCents`: `(SELECT CAST(COALESCE(SUM(be.amount_cents), 0) AS int) FROM billing_events be JOIN executions e ON e.id = be.execution_id WHERE e.objective_id = objectives.id AND be.event_type = 'tool_invoked')` typed as `number`
      - `bestBotClass`: `(SELECT ac.current_class FROM agent_classes ac JOIN bots b ON b.id = ac.bot_id JOIN executions e ON e.id = b.execution_id WHERE e.objective_id = objectives.id ORDER BY CASE ac.current_class WHEN 'Artisan' THEN 3 WHEN 'Understudy' THEN 2 WHEN 'Novice' THEN 1 WHEN 'Retired' THEN 0 ELSE -1 END DESC LIMIT 1)` typed as `string | null`
    - Filter: `WHERE is_archived = false`
    - Order: `created_at DESC`

    **3. GET /:id (get single objective, supports OBJ-02 pre-fill)**
    - Params schema: `{ id: String(format: 'uuid') }`
    - Response 200: full objective object (no aggregation needed). Response 404: `{ error: string }`.
    - Handler: `db.select().from(objectives).where(eq(objectives.id, id))`. Return first row or 404.

    **4. DELETE /:id (delete objective, OBJ-04)**
    - Params schema: `{ id: String(format: 'uuid') }`
    - Response 200: `{ success: true }`. Response 404: `{ error: string }`.
    - PreHandler: `verifyAuthToken`
    - Handler: `db.delete(objectives).where(eq(objectives.id, id)).returning({ id: objectives.id })`. If 0 rows returned, 404. The FK `ON DELETE SET NULL` on executions.objective_id handles the cascade automatically.

    **5. PATCH /:id (update/archive objective, OBJ-04)**
    - Params schema: `{ id: String(format: 'uuid') }`
    - Body schema: `Type.Partial(Type.Object({ name: String(minLength:1, maxLength:255), description: String(), defaultMaxBots: Integer(minimum:3, maximum:20), defaultBudgetCapCents: Integer(minimum:0), defaultRuntimeLimitSeconds: Integer(minimum:60), defaultAllowedTools: Array(String()), isArchived: Boolean() }))`
    - Response 200: updated objective object. Response 404: `{ error: string }`.
    - PreHandler: `verifyAuthToken`
    - Handler: Build an `updates` object containing only fields that are `!== undefined` in the body. Always set `updatedAt: new Date()`. Use `db.update(objectives).set(updates).where(eq(objectives.id, id)).returning()`. If 0 rows, 404. Return the full updated row.

    **CORS note:** The app.ts CORS config currently allows only `['GET', 'POST', 'OPTIONS']`. PATCH and DELETE need to be added. Update the `methods` array in app.ts to include `'PATCH'` and `'DELETE'`.

    **TypeBox response schemas:** For the objective response object, define a reusable `ObjectiveSchema` constant at the top of the file containing all 10 base fields. For the list response, extend it with the 4 aggregation fields. Use `Type.Unsafe<Date>({ type: 'string', format: 'date-time' })` for timestamp fields (matching executions.ts pattern). Use `Type.Union([Type.String(), Type.Null()])` for nullable fields.
