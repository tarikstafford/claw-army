  <action>
Add two new GET endpoints to the existing `objectivesRoutes` plugin in `objectives.ts`. Import `tasks`, `billingEvents`, `bots`, `telemetry`, `agentClasses` from `@claw/db` as needed alongside the existing imports.

**Endpoint 1: `GET /:id/executions` (HUB-01)**

Register BEFORE the existing `GET /:id` handler (Fastify's Radix tree handles this correctly, but ordering avoids ambiguity during code review).

Schema:
- params: `{ id: Type.String({ format: 'uuid' }) }`
- response 200: `Type.Array(Type.Object({ id (uuid), status (string), objective (string), createdAt (date-time), totalCostCents (integer), botCount (integer), avgCompositeScore (union number|null) }))`
- response 404: `Type.Object({ error: Type.String() })`

Handler:
1. Verify objective exists: `SELECT id FROM objectives WHERE id = :id`. If not found, return 404.
2. Query executions with correlated subqueries (matching the pattern already in GET /objectives):
   - `totalCostCents`: `SELECT CAST(COALESCE(SUM(be.amount_cents), 0) AS int) FROM billing_events be WHERE be.execution_id = executions.id AND be.event_type = 'tool_invoked'`
   - `botCount`: `SELECT CAST(COUNT(*) AS int) FROM bots b WHERE b.execution_id = executions.id`
   - `avgCompositeScore`: `SELECT CAST(AVG(b.composite_score) AS float) FROM bots b WHERE b.execution_id = executions.id AND b.composite_score IS NOT NULL` (use CAST AS float to avoid string return from PostgreSQL numeric type -- see Research pitfall 1)
3. Filter: `WHERE executions.objective_id = :id`
4. Order: `ORDER BY executions.created_at DESC`
5. Return array of rows.

**Endpoint 2: `GET /:id/stats` (HUB-02 + HUB-04)**

Schema:
- params: `{ id: Type.String({ format: 'uuid' }) }`
- response 200: `Type.Object({ totalSpendCents (integer), totalTasksCompleted (integer), totalBotHours (number), runCount (integer), classBreakdown: { novice (integer), understudy (integer), artisan (integer), retired (integer) }, classTrendSummary (string) })`
- response 404: `Type.Object({ error: Type.String() })`

Handler:
1. Verify objective exists. If not found, return 404.
2. Query aggregate stats using correlated subqueries or JOINs against the objectives table:
   - `runCount`: `COUNT(*) FROM executions WHERE objective_id = :id`
   - `totalSpendCents`: `COALESCE(SUM(be.amount_cents), 0) FROM billing_events be JOIN executions e ON e.id = be.execution_id WHERE e.objective_id = :id AND be.event_type = 'tool_invoked'`
   - `totalTasksCompleted`: `COUNT(*) FROM tasks t JOIN executions e ON e.id = t.execution_id WHERE e.objective_id = :id AND t.status = 'completed'`
   - `totalBotHours`: `COALESCE(SUM(t.metric_value), 0) FROM telemetry t JOIN executions e ON e.id = t.execution_id WHERE e.objective_id = :id AND t.metric_name = 'bot_hours'` (cast as float)
3. Query class breakdown: `SELECT ac.current_class, COUNT(*) FROM agent_classes ac JOIN bots b ON b.id = ac.bot_id JOIN executions e ON e.id = b.execution_id WHERE e.objective_id = :id GROUP BY ac.current_class`
4. Build `classBreakdown` object from query results (default 0 for missing classes).
5. Build `classTrendSummary` string: e.g. "3 Artisans, 2 Understudies, 5 Novices across {runCount} runs". If runCount is 0: "No runs yet".

Use separate queries (not one massive query) for clarity and maintainability. Each query is small. The handler runs at most 3-4 queries, all indexed.

```typescript
export interface Objective {
  id: string;
  name: string;
  description: string | null;
  defaultMaxBots: number;
  defaultBudgetCapCents: number | null;
  defaultRuntimeLimitSeconds: number | null;
  defaultAllowedTools: string[];

  lastRunStatus: string | null;
  runCount: number;
  totalSpendCents: number;
  bestBotClass: 'Novice' | 'Understudy' | 'Artisan' | 'Retired' | null;
}

export interface ObjectiveRun {
  id: string;
  status: 'queued' | 'running' | 'paused' | 'stopped' | 'completed' | 'failed';
  objective: string;
  createdAt: string;
  totalCostCents: number;
  botCount: number;
  avgCompositeScore: number | null;
}

export interface ObjectiveStats {
  totalSpendCents: number;
  totalTasksCompleted: number;
  totalBotHours: number;
  runCount: number;
  classBreakdown: {
    novice: number;
    understudy: number;
    artisan: number;
    retired: number;
  };
  classTrendSummary: string;
}
```
