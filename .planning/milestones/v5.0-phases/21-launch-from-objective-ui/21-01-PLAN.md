**api.ts** — Add `objectiveId?: string` to the `createExecution()` body parameter type (line 32-36 area). The function already passes `body` straight through to `JSON.stringify(body)`, so adding the optional field to the type is the only change needed. When `objectiveId` is undefined, `JSON.stringify` omits it automatically.

Update the body type from:
```typescript
body: {
  objective: string;
  maxBots: number;
  budgetCapCents: number;
  allowedTools: string[];
}
```
to:
```typescript
body: {
  objective: string;
  maxBots: number;
  budgetCapCents: number;
  allowedTools: string[];
  objectiveId?: string;
}
```

**+page.server.ts** — In the `default` action, after the existing form field extraction block (after line 32, the `allowedDomains` parsing):

1. Add `objectiveId` extraction:
```typescript
const objectiveId = (formData.get('objectiveId') as string | null)?.trim() || null;
```

2. In the `JSON.stringify` call on line 53, change from:
```typescript
body: JSON.stringify({ objective, maxBots, budgetCapCents, llmProvider, allowedDomains }),
```
to:
```typescript
body: JSON.stringify({
  objective,
  maxBots,
  budgetCapCents,
  llmProvider,
  allowedDomains,
  ...(objectiveId ? { objectiveId } : {}),
}),
```

CRITICAL: Use the spread conditional `...(objectiveId ? { objectiveId } : {})` — do NOT send `objectiveId: null`. The backend TypeBox schema is `Type.Optional(Type.String({ format: 'uuid' }))` which rejects `null`. Omitting the field when there's no objectiveId is the correct approach.

In `new-execution/+page.svelte`:

**1. Add `page` import** — at the top of the `<script>` block, add:
```typescript
import { page } from '$app/state';
```
This is the Svelte 5 rune-based import (NOT `$app/stores`). It's already used in `objectives/[id]/+page.svelte`.

**2. Add objectiveId $state** — alongside the existing state declarations (after line 21, the `submitting` state):
```typescript
let objectiveId = $state('');
```

**3. Add $derived for URL params** — after the state declarations:
```typescript
const urlObjectiveId = $derived(page.url.searchParams.get('objectiveId') ?? '');
const urlMaxBots = $derived(Number(page.url.searchParams.get('maxBots') ?? '0'));
const urlBudgetCapDollars = $derived(Number(page.url.searchParams.get('budgetCapDollars') ?? '0'));
```

**4. Add $effect to initialize state from URL params** — after the $derived declarations:
```typescript
$effect(() => {
  if (urlObjectiveId) {
    objectiveId = urlObjectiveId;
  }
  if (urlMaxBots > 0) {
    maxBots = urlMaxBots;
  }
  if (urlBudgetCapDollars > 0) {
    budgetCapDollars = urlBudgetCapDollars;
  }
});
```

Use `$state` for the form field values (mutable, user can override) and `$effect` for one-time initialization from URL params. Do NOT use `$derived` for the form values themselves — that would make them read-only (Pitfall 2 from research).

**5. Add hidden input inside the form** — immediately after the opening `<form>` tag (line 64 area, after `use:enhance`), add:
```svelte
{#if objectiveId}
  <input type="hidden" name="objectiveId" value={objectiveId} />
{/if}
```

This is CRITICAL. Without this hidden input, objectiveId is silently dropped from the form POST because URL params are NOT included in formData (Pitfall 1 from research). The server action reads from `formData.get('objectiveId')` which requires this hidden field.
