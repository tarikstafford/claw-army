The guide page is 1,328 lines — the largest single page in the app. It has 39 old token references and uses "Claw Army" throughout the body copy. Two changes are needed: (a) CSS restyle, and (b) brand copy substitution.

**Part A: Brand copy substitution**

Search for all instances of "Claw Army" (case-insensitive) and replace with "Akasa". This includes:
- `<title>Guide | Claw Army</title>` → `<title>Guide | Akasa</title>`
- Page headings mentioning "Claw Army"
- Body copy paragraphs (e.g., "Claw Army turns a plain-language objective..." → "Akasa turns a plain-language objective...")
- Any alt text, aria-labels, or data attributes

Do NOT rewrite the guide content beyond brand name substitution. The copy voice and structure stay the same — only the product name changes. Per research recommendation, deep copy rewriting is beyond Phase 23 scope.

**Part B: CSS restyle**

Apply full token replacement across the `<style>` block:

Page-level:
- Page background → `var(--bg)`
- Section backgrounds → alternating `var(--bg)` and `var(--bg-2)`

Typography:
- Main heading → `font-family: var(--font-display); color: var(--text)`
- Section headings (h2) → `font-family: var(--font-display); color: var(--text)`
- Sub-headings (h3) → `color: var(--text); font-weight: 500`
- Body text → `font-family: var(--font-body); color: var(--text-muted)`
- Section eyebrow labels → `var(--font-mono); font-size: 10px; letter-spacing: 0.15em; text-transform: uppercase; color: var(--text-faint)`

Cards (feature cards, step cards, etc.):
- Background → `var(--bg-card)`
- Border → `1px solid var(--border)`
- Border-radius → `14px`
- Hover → `border-color: var(--border-mid)`

Code blocks:
- Background → `var(--bg-2)`
- Border → `1px solid var(--border)`
- Text → `var(--font-mono); color: var(--text)`

Lists:
- List markers → `color: var(--violet-bright)`
- List text → `color: var(--text-muted)`

Callout boxes / notes:
- Background → `var(--violet-dim)` or `var(--bg-3)`
- Border-left → `3px solid var(--violet)`
- Text → `color: var(--text-muted)`

Icons/decorative elements:
- Icon colors → `var(--violet-bright)` or `var(--text-faint)`
- Decorative borders → `var(--border)`

Soul/DNA-related sections:
- Any references to soul concepts → use amber accents (`var(--amber)`)
- Tier explanations → Artisan=amber, Understudy=teal, Novice=muted, Retired=rose

Links:
- `color: var(--violet-bright)` with hover `color: var(--violet-light)`

Replace all old tokens (`--signal`, `--canvas`, `--surface-*`, `--text-primary`, `--text-secondary`, `--active`, `--alert`, `--critical`) with Akasa equivalents.

Replace all hardcoded hex values with appropriate Akasa tokens.

Do NOT change any JavaScript logic or component behavior.
