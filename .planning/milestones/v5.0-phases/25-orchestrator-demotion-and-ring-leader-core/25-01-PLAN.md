  <name>Task 1: Create task-graph-parser.ts with LLM-based DAG decomposition</name>
  <files>services/execution-service/src/services/task-graph-parser.ts</files>
  <action>
Create `task-graph-parser.ts` that exports `parseObjectiveToTaskGraph(objective: string, allowedTools: string[], maxTasks: number): Promise<TaskGraph>`.

Implementation:
1. Import `TaskGraph`, `TaskGraphNode`, `TaskComplexity`, `MIN_AGENTS_PER_TASK` from `@claw/shared-types`.
2. Use the same AI SDK `generateText` pattern as existing `planner.service.ts` (import from `ai`, use `resolveModel` helper).
3. The LLM system prompt must instruct the model to return a JSON object with:
   - `tasks`: array of objects with `taskId` (string, e.g. "task-1"), `description`, `complexity` ("low"|"medium"|"high"), `requiredTools` (subset of allowedTools), `dependencies` (taskId references, empty array for root tasks).
   - The prompt must explicitly state: "Only use tools from the provided allowedTools list: [tools]. If no specific tools are required, use an empty array."
4. Parse the LLM response. For each task node:
   - Set `parallelizable: true` if `dependencies.length === 0`, else false.
   - Set `minPopulation` to `MIN_AGENTS_PER_TASK` (always 3).
   - Set `recommendedPopulation` based on complexity: low=3, medium=4, high=5.
5. Build the `dag` adjacency map: for each task, if task B depends on task A, then `dag[A]` includes B (A -> B means A must complete before B starts).
6. Validate the DAG has no cycles using a topological sort (Kahn's algorithm). If a cycle is detected, throw an error with the specific cycle path.
7. Validate every `dependencies` reference points to an existing `taskId`. Throw if dangling reference found.
8. Fallback: if LLM output is not valid JSON or fails validation, produce a simple flat graph (all tasks independent, medium complexity, no dependencies) — same resilience pattern as existing planner.

Export a standalone `validateTaskGraphDAG(graph: TaskGraph): { valid: boolean; error?: string }` function for use by pre-flight validation in plan 25-02.
  </action>

Run `pnpm --filter @claw/execution-service exec tsc --noEmit` — zero type errors. Verify the file imports TaskGraph from @claw/shared-types and exports parseObjectiveToTaskGraph and validateTaskGraphDAG.
  </verify>
  <done>
`parseObjectiveToTaskGraph` accepts objective + allowedTools + maxTasks and returns a validated TaskGraph. DAG cycle detection and dangling reference validation are in place. Fallback produces valid flat graph on LLM failure.
  </done>
