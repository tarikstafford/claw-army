Create `preflight-validator.ts` that exports:

**Types:**
```typescript
interface PreFlightError {
  code: 'TOOL_GRANT_INSUFFICIENT' | 'BUDGET_INSUFFICIENT' | 'INVALID_TASK_GRAPH';
  message: string;
  details: Record<string, unknown>;
}

interface PreFlightResult {
  valid: boolean;
  errors: PreFlightError[];
  totalMinPopulation: number;      // sum of minPopulation across all tasks
  totalRecommendedPopulation: number; // sum of recommendedPopulation
  estimatedMinCostCents: number;   // rough floor estimate for budget check
}
```

**Function: `validatePreFlight(taskGraph: TaskGraph, toolGrants: string[], budgetCapCents: number): PreFlightResult`**

Validation steps (run all, accumulate errors):

1. **Structural validation**: Call `validateTaskGraphDAG(taskGraph)` from task-graph-parser. If invalid, add error with code `INVALID_TASK_GRAPH`.

2. **Tool grant validation**: For each task node, check that every item in `requiredTools` is present in `toolGrants`. If not, add an error with code `TOOL_GRANT_INSUFFICIENT`. The message must name the missing tools and the affected task(s). Example: `"Tasks [task-1, task-3] require tools [web_search, code_execute] which are not in the granted tool set"`. Aggregate: collect all missing tools across all tasks into a single error (not one per task).

3. **Budget validation**:
   - Compute `totalMinPopulation` = sum of `minPopulation` across all task nodes.
   - Use a cost-per-agent estimate: read from `process.env.ESTIMATED_AGENT_COST_CENTS` or default to 50 cents (conservative placeholder — this will be refined in Phase 27 when real cost estimation is built).
   - `estimatedMinCostCents = totalMinPopulation * costPerAgent`.
   - If `budgetCapCents > 0` (budget cap enabled) and `estimatedMinCostCents > budgetCapCents`, add error with code `BUDGET_INSUFFICIENT`. Message: `"Budget cap of ${budgetCapCents}c cannot fund the minimum population of ${totalMinPopulation} agents (estimated minimum cost: ${estimatedMinCostCents}c). Increase budget to at least ${estimatedMinCostCents}c or reduce objective scope."` Include in details: `{ totalMinPopulation, estimatedMinCostCents, budgetCapCents, shortfallCents: estimatedMinCostCents - budgetCapCents }`.

4. Compute `totalRecommendedPopulation` = sum of `recommendedPopulation`.

Return `{ valid: errors.length === 0, errors, totalMinPopulation, totalRecommendedPopulation, estimatedMinCostCents }`.

Note: budgetCapCents of 0 means "no cap" (existing behavior from v1.0) — skip budget validation when 0.
