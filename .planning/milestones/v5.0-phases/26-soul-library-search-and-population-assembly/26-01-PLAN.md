Create `soul-library-search.ts` in the execution-service services directory. This is the Ring Leader's library search engine — it replaces the simple `queryHistoricalParents` from `soul-generator.ts` with a multi-dimensional filtered search.

**Export interfaces:**

```typescript
export interface SoulSearchParams {
  taskDescription: string;        // used to generate embedding for similarity search
  taskCategory: string;           // from task graph node classification
  requiredTools: string[];        // tools the task requires
  taskComplexity: TaskComplexity; // 'low' | 'medium' | 'high'
  campaignType: CampaignType;     // 'ad_hoc' | 'campaign'
  requiredPopulation: number;     // how many souls needed (search returns 2x this)
}

export interface SoulSearchResult {
  soulId: string;
  soulContent: string;
  embedding: number[];
  agentClass: 'Artisan' | 'Understudy' | 'Novice';
  generation: number;
  parentSoulId: string | null;
  taskCategory: string;
  compositeScore: number | null;  // from bots table if available
  similarityScore: number;        // cosine similarity to task description
  campaignBoost: number;          // 0 or positive boost for campaign souls
  finalRank: number;              // similarity + campaignBoost
}
```

**Export function `searchSoulLibrary(params: SoulSearchParams): Promise<SoulSearchResult[]>`:**

1. **Generate task embedding:** Use `embed` from `ai` with `openai.embeddingModel('text-embedding-3-small')` to embed `params.taskDescription`. Import from `ai` and `@ai-sdk/openai` (already dependencies of execution-service — see soul-generator.ts).

2. **Query bot_souls with pgvector:** Use a raw SQL query via drizzle's `sql` template tag to compute cosine similarity between the task embedding and `bot_souls.embedding` column. Filter to rows where:
   - `bot_souls.embedding IS NOT NULL`
   - `bot_souls.is_archetype = false` (archetypes are handled separately in pioneer path)
   - `bot_souls.task_category = params.taskCategory`
   - Cosine similarity >= `SOUL_SEARCH_SIMILARITY_THRESHOLD` (0.78 from shared-types)

   Use pgvector's `<=>` operator for cosine distance: `1 - (embedding <=> $taskEmbedding)` gives similarity. Order by similarity DESC.

3. **Negative signal exclusion (SOUL-02):** LEFT JOIN against `negative_signal_register` on `soul_id` and filter WHERE `negative_signal_register.id IS NULL`. This excludes any soul that has ANY negative signal entry. The negative_signal_register does not have a task_category column, so exclude by soul_id alone (any soul with a negative signal for any reason is excluded).

4. **Agent class lookup:** LEFT JOIN `agent_classes` on `bot_souls.bot_id = agent_classes.bot_id AND agent_classes.task_category = params.taskCategory`. Extract `current_class` (default to 'Novice' if no agent_class row exists).

5. **Required tools filter:** After fetching results, filter in application code — parse `bot_souls.dimensions` JSONB to extract `toolUsageDoctrine` text, and check that every tool in `params.requiredTools` appears (case-insensitive substring match). If `requiredTools` is empty, skip this filter.

6. **Task complexity filter:** Filter in application code — for 'high' complexity tasks, exclude 'Novice' class souls (only Artisan and Understudy can handle high complexity). For 'medium', allow all classes. For 'low', allow all classes.

7. **Campaign type weighting:** For `campaignType === 'campaign'`, give a +0.05 boost to souls that have been used in prior executions within the same task category more than once (check by counting `bot_souls` rows with same `parentSoulId` lineage). For 'ad_hoc', no boost.

8. **Compute finalRank:** `similarityScore + campaignBoost`. Sort results by finalRank DESC.

9. **Return 2x pool (SOUL-03):** Slice to `params.requiredPopulation * 2` results. If fewer results are available, return all available results (caller handles insufficient results in pioneer path).

Import constants from `@claw/shared-types`: `SOUL_SEARCH_SIMILARITY_THRESHOLD`, `TaskComplexity`, `CampaignType`.

Import `embed` from `ai` and `openai` from `@ai-sdk/openai`.
Import `sql`, `eq`, `and`, `isNull`, `desc` from `drizzle-orm`.
