**Constants:**

```typescript
export const AGENT_COST_CENTS: Record<'Artisan' | 'Understudy' | 'Novice', number> = {
  Artisan: 100,
  Understudy: 50,
  Novice: 30,
};
```

**`estimatePopulationCost(manifests: PopulationManifest[]): number`**
- Sum cost of every soul across all manifests using AGENT_COST_CENTS[soul.agentClass]
- Return total in cents

**`applyTieredReduction(manifests: PopulationManifest[], budgetCapCents: number): { manifests: PopulationManifest[]; warnings: string[]; }`**
- Deep-clone manifests before mutating
- **Tier 1 — Artisan replacement:** For each task, replace every Artisan soul entry with agentClass='Understudy'. If cost now fits budget, return with warning "Tier 1 reduction: replaced N Artisans with Understudies to fit budget cap of Xc"
- Re-estimate cost after Tier 1. If within budget, return early.
- **Tier 2 — Population reduction:** For each task, if assignedSouls.length > MIN_AGENTS_PER_TASK (3), truncate to first 3 souls. Add warning "Tier 2 reduction: reduced task {taskId} from N to 3 agents"
- Re-estimate cost after Tier 2. Return manifests and warnings.
- IMPORTANT: Never reduce any task below MIN_AGENTS_PER_TASK (3) agents — this is the hard floor per BUDG-03.

**`validateBudget(manifests: PopulationManifest[], budgetCapCents: number): BudgetValidationResult`**
- If budgetCapCents === 0, return `{ funded: true, manifests, warnings: [], estimatedCostCents }` (no-cap mode)
- Estimate cost. If within budget, return funded=true with original manifests.
- Apply tiered reduction. Re-estimate. If within budget, return funded=true with reduced manifests + warnings.
- If still over budget after full reduction, compute shortfall: `minimumCost - budgetCapCents`. Return `{ funded: false, manifests: reducedManifests, warnings, estimatedCostCents: minimumCost, shortfallCents, minimumRequiredCents: minimumCost }`

**Types:**
```typescript
export interface BudgetValidationResult {
  funded: boolean;
  manifests: PopulationManifest[];
  warnings: string[];
  estimatedCostCents: number;
  shortfallCents?: number;          // only when funded=false
  minimumRequiredCents?: number;    // only when funded=false
}
```
