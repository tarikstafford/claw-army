Create `agent-spawner.ts` in services/execution-service/src/services/.

This is the core spawning orchestrator. It takes a validated population manifest + mission brief, computes spawn waves from the DAG, and spawns agents per wave — waiting for upstream task completion before spawning dependent tasks.

**Types:**

```typescript
interface ActiveSession {
  sessionId: string;         // from OpenClaw sendTask return
  botId: string;
  soulId: string;
  taskId: string;
  agentClass: string;
  sessionJwt: string;
  spawnedAt: Date;
  status: 'spawning' | 'active' | 'completed' | 'failed';
}

interface ActiveSessionRegistry {
  runId: string;
  sessions: Map<string, ActiveSession>;  // keyed by sessionId
}

interface SpawnResult {
  totalAgentsSpawned: number;
  totalWaves: number;
  registry: ActiveSessionRegistry;
}
```

**Module-level registry:**
- `const registries = new Map<string, ActiveSessionRegistry>()` — keyed by ringLeaderRunId
- Export `getActiveSessionRegistry(runId: string): ActiveSessionRegistry | undefined`
- Export `getAllActiveRegistries(): Map<string, ActiveSessionRegistry>`

**Export `spawnAgentsForRun(params: SpawnParams): Promise<SpawnResult>`** where:
```typescript
interface SpawnParams {
  ringLeaderRunId: string;
  executionId: string;
  missionBrief: RingLeaderMissionBrief;
  manifests: PopulationManifest[];
}
```

Implementation:

1. **Compute spawn waves from DAG** (SPAWN-06):
   - Extract `taskGraph.dag` from missionBrief (Record<string, string[]> — taskId -> downstream taskIds)
   - Build reverse dependency map: for each taskId, which upstream tasks must complete first
   - Topological sort into waves: Wave 0 = tasks with no upstream deps, Wave N = tasks whose deps are all in waves < N
   - Log the wave plan: `[agent-spawner] Spawn wave plan: wave0=[taskA,taskB], wave1=[taskC], ...`

2. **Process waves sequentially:**
   For each wave:
   a. Collect all manifests for tasks in this wave
   b. For each manifest, for each assignedSoul:
      - Look up full soul data from bot_souls table (need soulContent and constitutionDirectives): `db.select().from(botSouls).where(eq(botSouls.id, soul.soulId))`
      - Call `mintSessionJwt()` from session-jwt.ts with: soulId, taskId, toolAllowlist (from missionBrief.toolGrants), thirdPartyGrants ([] for now — placeholder until external integrations), budgetAllocationCents (from AGENT_COST_CENTS[soul.agentClass] in budget-validator.ts), runtimeLimitSeconds (from missionBrief.runtimeLimitSeconds), ringLeaderRunId
      - Collect upstream outputs for this task: query completed tasks from earlier waves by taskId from the `tasks` table where status='completed', extract result text as summary. Pass as `upstreamOutputs` to buildAgentSessionPrompt. For wave 0 tasks, upstreamOutputs is null.
      - Call `buildAgentSessionPrompt()` with soulContent, constitutionDirectives, task description, taskId, requiredTools, complexity, upstreamOutputs
      - If constitutionVerified is false, log WARN: `[agent-spawner] Constitution verification failed for soul ${soulId} on task ${taskId}: missing ${missing.join(', ')}`
      - Call `spawnBot(executionId, soul.soulId, sessionPrompt.fullPrompt)` from bot-orchestrator.ts — this creates the GCE VM with the full prompt as soulContent (the GCE launcher writes it to SOUL.md in the workspace)
      - Create ActiveSession entry with status 'spawning', add to registry
   c. Spawn all agents in this wave in parallel using `Promise.allSettled()` — failures logged but don't block other agents
   d. Log wave completion: `[agent-spawner] Wave ${n} complete: ${spawned}/${total} agents spawned`
   e. After wave completes, mark registry entries as 'active' for successful spawns, 'failed' for rejected promises

3. **After all waves:** Update ring_leader_runs.runState with registry snapshot (session count, wave count, any failures). Transition status to 'coordinating' (the next phase will pick up from here).

4. **Return SpawnResult** with totalAgentsSpawned, totalWaves, and the registry reference.

Import: mintSessionJwt from './session-jwt', buildAgentSessionPrompt from './agent-session-builder', spawnBot from '../orchestrator/bot-orchestrator', AGENT_COST_CENTS from './budget-validator', db/botSouls/tasks/ringLeaderRuns from '@claw/db', PopulationManifest/RingLeaderMissionBrief/TaskGraphNode from '@claw/shared-types'.
