**Endpoint 1: GET /ring-leader/runs/:runId/manifest** (SPAWN-07)

Returns the full population manifest for a Ring Leader run — the pre-flight dashboard data.

Schema:
- Params: `{ runId: Type.String({ format: 'uuid' }) }`
- Response 200: `Type.Object({ runId, executionId, status, manifests: Type.Array(ManifestSchema), missionBrief: Type.Unknown() })`
  where ManifestSchema is:
  ```
  Type.Object({
    taskId: Type.String(),
    taskDescription: Type.String(),
    assignedSouls: Type.Array(Type.Object({
      soulId: Type.String({ format: 'uuid' }),
      agentClass: Type.Union([Type.Literal('Artisan'), Type.Literal('Understudy'), Type.Literal('Novice')]),
      source: Type.Union([Type.Literal('library'), Type.Literal('generated'), Type.Literal('mutated')]),
      parentSoulId: Type.Union([Type.String({ format: 'uuid' }), Type.Null()]),
      mutationApplied: Type.Union([Type.String(), Type.Null()]),
      selectionRationale: Type.String(),
      differentiationScore: Type.Number(),
    })),
    pioneerFlag: Type.Boolean(),
    varianceIntent: Type.Union([Type.String(), Type.Null()]),
  })
  ```
- Response 404: `Type.Object({ error: Type.String() })`

Handler:
1. Query ring_leader_runs by id: `db.select().from(ringLeaderRuns).where(eq(ringLeaderRuns.id, runId))`
2. If not found, return 404
3. Cast populationManifest JSONB to PopulationManifest[] (import type from @claw/shared-types)
4. If populationManifest is null (still assembling), return 200 with empty manifests array and a note in status
5. Return full response: runId, executionId, status, manifests, missionBrief

**Endpoint 2: GET /ring-leader/runs/by-execution/:executionId**

Convenience endpoint to look up the Ring Leader run for an execution (the UI knows executionId, not runId).

Schema:
- Params: `{ executionId: Type.String({ format: 'uuid' }) }`
- Response 200: same shape as endpoint 1
- Response 404: `Type.Object({ error: Type.String() })`

Handler:
1. Query ring_leader_runs by executionId: `db.select().from(ringLeaderRuns).where(eq(ringLeaderRuns.executionId, executionId))`
2. If not found, return 404
3. Return same response shape as endpoint 1

Import: Type from @sinclair/typebox, FastifyPluginAsyncTypebox from @fastify/type-provider-typebox, db/ringLeaderRuns from @claw/db, eq from drizzle-orm, PopulationManifest from @claw/shared-types.
