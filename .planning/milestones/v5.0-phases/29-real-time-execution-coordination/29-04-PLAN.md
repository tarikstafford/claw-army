Create drift-detector.ts implementing COORD-06 and COORD-07:

1. **`createDriftDetector()`** — factory returning a `CoordinationModule` with `name: 'drift-detector'`.

2. **Module-level state** per runId:
   - `objectiveEmbedding: number[] | null` — cached embedding of the original objective (computed once on first poll)
   - `lastReanchoringAt: number` — timestamp of last reanchoring signal (debounce: no more than one per 2 minutes)
   - `reanchoringCount: number` — total reanchoring signals sent this run

3. **`execute(ctx: CoordinationContext)`** implementation:

   **A. Compute objective embedding (once):**
   - On first call, generate embedding for `ctx.missionBrief.objective` using the same `embed` function from the `ai` SDK and `openai.embeddingModel('text-embedding-3-small')` as used in soul-library-search.ts
   - Cache in module-level state

   **B. Collect completed outputs:**
   - Query tasks table WHERE `executionId = ctx.executionId AND status = 'completed' AND result IS NOT NULL`
   - Concatenate all result texts (truncated to 500 chars each to keep embedding input manageable)
   - If no completed results yet, set drift score to 0 (no drift measurable) and return

   **C. Compute drift score:**
   - Generate embedding for the concatenated output text (truncated to 8000 chars total to stay within embedding model limits)
   - Compute cosine similarity between objective embedding and output embedding
   - `driftScore = 1 - cosineSimilarity` (0 = perfectly aligned, 1 = fully diverged)
   - Update `ctx.runState.objectiveDriftScore = driftScore`

   **D. Reanchoring signal (COORD-07):**
   - If `driftScore > DRIFT_REANCHORING_THRESHOLD` (0.35 from shared-types) AND more than 120s since lastReanchoringAt:
     - Construct reanchoring signal:
       - `objectiveRestatement`: `ctx.missionBrief.objective` (verbatim)
       - `driftSummary`: "Collective output drift score {driftScore.toFixed(3)} exceeds threshold 0.35. {completedCount}/{totalTasks} tasks have completed outputs. Reanchoring signal #{reanchoringCount+1}."
       - `reorientationDirective`: "Refocus on the original objective. Completed outputs are diverging from the stated goal. Prioritize alignment with: {objective first 200 chars}"
     - Log via `logCoordinationEvent` with `ReanchoringEvent` payload
     - Add "Drift threshold exceeded: {driftScore}" to `ctx.runState.anomalies`
     - Update lastReanchoringAt and increment reanchoringCount
   - If driftScore <= threshold: no action (normal operation)

4. **Cosine similarity helper** — implement inline:
```typescript
function cosineSimilarity(a: number[], b: number[]): number {
  let dot = 0, normA = 0, normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}
```

5. **Error handling**: Wrap embedding calls in try/catch. If embedding fails, set driftScore to previous value (or 0 on first failure) and log WARN. Do NOT let embedding API failures crash the coordination loop.
