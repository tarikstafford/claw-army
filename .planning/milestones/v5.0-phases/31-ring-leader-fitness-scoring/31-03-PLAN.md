  <action>
Create `ring-leader-fitness.ts` that exports `computeAndPersistFitness()`.

**Params interface (FitnessParams):**
- runId: string (ring_leader_runs.id)
- executionId: string
- synthesis: RingLeaderSynthesis
- manifests: PopulationManifest[]
- missionBrief: RingLeaderMissionBrief
- runState: RingLeaderRunState
- coordinationLog: CoordinationLogEntry[]

**Steps:**

1. **Call both scorers in parallel** using Promise.all:
   - `scoreCoordinationQuality({ synthesis, coordinationLog, missionBrief, runState })`
   - `scoreSoulSelectionQuality({ synthesis, manifests, missionBrief })`

2. **Compute composite score (FIT-03):**
   Import FITNESS_CATEGORY_WEIGHTS from @claw/shared-types.
   ```
   const coordWeighted = (coordScore.collectiveOutcome * 0.40 + coordScore.driftPrevention * 0.25 + coordScore.reallocationEffectiveness * 0.20 + coordScore.budgetManagement * 0.15);
   const selectionWeighted = (selScore.librarySearchQuality + selScore.differentiationEffectiveness + selScore.mutationDecisionQuality + selScore.pioneerHandling + selScore.selectionRetrospectiveQuality) / 5;
   const compositeScore = coordWeighted * FITNESS_CATEGORY_WEIGHTS.coordination + selectionWeighted * FITNESS_CATEGORY_WEIGHTS.soulSelection;
   ```
   Round compositeScore to 2 decimal places.

3. **Derive FIT-04 Akashic Library metadata from manifests:**
   - soulSelectionLog: the full manifests array (PopulationManifest[] — snapshot of all soul assignments)
   - librarySearchQueries: derive from manifests — for each task, extract `{ taskId, taskDescription, soulCount: assignedSouls.length, sources: unique source types, pioneerFlag }`
   - selectionRetrospective: synthesis.soulSelectionRetrospective (the Ring Leader's own assessment)
   - pioneerTasksHandled: count of manifests where pioneerFlag === true
   - mutationOperationsApplied: count of souls across all manifests where mutationApplied !== null
   - mutationSuccessRate: of mutated souls, what fraction are on completed tasks? numerator = mutated souls on completed tasks (from synthesis.taskSummary), denominator = total mutated souls. If denominator is 0, set to null. Format as string with 3 decimal places for numeric(4,3) column.

4. **Persist to ring_leader_fitness table:**
   ```typescript
   await db.insert(ringLeaderFitness).values({
     ringLeaderRunId: runId,
     coordinationScore: coordScore,
     soulSelectionScore: selScore,
     compositeScore: compositeScore.toFixed(2),
     soulSelectionLog: manifests,
     librarySearchQueries: searchQuerySummary,
     selectionRetrospective: synthesis.soulSelectionRetrospective,
     pioneerTasksHandled: pioneerCount,
     mutationOperationsApplied: mutationCount,
     mutationSuccessRate: mutationRate,
   });
   ```

5. **Log:** `[ring-leader-fitness] Persisted fitness for runId={runId} composite={compositeScore} coordination={coordWeighted} soulSelection={selectionWeighted}`

6. **Error handling:** Wrap entire function in try/catch. On failure, log WARN and return without throwing — fitness scoring failure must NOT prevent run completion (same non-fatal pattern as synthesis fallback). Return the RingLeaderFitnessScore on success, or null on failure.

**Return type:** `RingLeaderFitnessScore | null`

   generateRunSynthesis({
     runId, executionId, missionBrief, runState: currentRunState,
