This file replicates Paperclip's startup sequence (from `startServer`) WITHOUT patching `startServer` itself. Read `paperclip/server/src/index.ts` to understand the exact startup steps (load config, create DB, apply migrations, call createApp, listen on port), then replicate that sequence in this file with the addition of passing `extraApiRouter: akasaRouter`.

The implementation must:
1. Import `createApp` from `../../../paperclip/server/src/app.js`
2. Import `createDb` and `applyPendingMigrations` from `@paperclipai/db`
3. Import config loading from Paperclip's config module (e.g., `../../../paperclip/server/src/config.js`)
4. Import `akasaRouter` from `./routes/index.js`
5. Replicate the startup sequence: load config -> create DB -> apply Paperclip migrations -> call `createApp(db, { ...opts, extraApiRouter: akasaRouter })` -> listen on port

Example structure (adapt based on what `paperclip/server/src/index.ts` actually does):
```typescript
import { createApp } from '../../../paperclip/server/src/app.js';
import { createDb, applyPendingMigrations } from '@paperclipai/db';
import { loadConfig } from '../../../paperclip/server/src/config.js';
import { akasaRouter } from './routes/index.js';

const config = loadConfig();
const db = createDb(config.databaseUrl);
await applyPendingMigrations(db);

const app = await createApp(db, {
  mode: config.mode,
  config,
  extraApiRouter: akasaRouter,
});

app.listen(config.port, () => {
  console.log(`[akasa-server] Listening on port ${config.port}`);
});
```

Do NOT import or call `startServer` from Paperclip -- replicate the sequence instead. This avoids needing to patch `startServer` and keeps Paperclip's `server/src/index.ts` completely unmodified.

**Step 2: Update `services/ui/vite.config.ts` proxy (Pitfall 6 prevention)**

The SvelteKit UI needs to proxy `/api` requests to the Express backend during development. Paperclip's Express server runs on port 3000 (verify from `paperclip/server/src/config.ts` -- if different, adjust accordingly).

Replace `services/ui/vite.config.ts` with:
```typescript
import { sveltekit } from '@sveltejs/kit/vite';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [sveltekit()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
      },
    },
  },
});
```

This routes all `/api/*` requests from the SvelteKit dev server (port 5173) to the Express backend (port 3000). The `changeOrigin: true` sets the `Host` header to the target URL.
