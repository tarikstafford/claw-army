**Step 2: Update app.html** (per D-03 zero-flash blocking script)

Write `services/ui/src/app.html`:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <link rel="icon" href="%sveltekit.assets%/favicon.png" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    %sveltekit.head%
  </head>
  <body data-sveltekit-preload-data="hover">
    <script>
      try {
        if (localStorage.getItem('akasa-mode') === 'back-office') {
          document.body.classList.add('back-office');
        }
      } catch (_) {}
    </script>
    <div style="display: contents">%sveltekit.body%</div>
  </body>
</html>
```

The script is placed as the first child of `<body>` so `document.body` is available. It runs synchronously before `%sveltekit.body%` renders, preventing any flash. The `try/catch` handles private browsing where localStorage throws.

The localStorage key is `akasa-mode` and the value to check is `back-office`. This key will be set by the toggle function added in Phase 3 components.
