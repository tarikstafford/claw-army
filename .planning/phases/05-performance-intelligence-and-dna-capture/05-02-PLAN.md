**Step 1: Create report-builder.ts (PERF-06).**

Create `services/execution-service/src/performance/report-builder.ts`.

Export `buildExecutionReport(executionId: string): Promise<ExecutionReport>`.

`ExecutionReport` interface:
```typescript
export interface ExecutionReport {
  executionId: string;
  totalBots: number;
  totalBotHours: number;          // sum from telemetry bot_hours rows
  totalCostCents: number;         // sum from billing_events WHERE event_type = 'tool_invoked'
  averageBotScore: number;        // average of bots.composite_score for this execution (0-100)
  topPerformingBotId: string | null;  // bot with highest composite_score
  errorDistribution: Record<string, number>;  // { "task_failure": N, "tool_rejection": M }
  costPerTaskCents: number;       // totalCostCents / total completed tasks (0 if none completed)
  totalTasks: number;
  completedTasks: number;
  failedTasks: number;
}
```

Queries (all using Drizzle ORM, matching existing patterns):
1. **Total bots**: `SELECT COUNT(*) FROM bots WHERE execution_id = $executionId` — use `sql<number>\`cast(count(*) as int)\``.
2. **Total bot-hours**: `SELECT COALESCE(SUM(metric_value::numeric), 0) FROM telemetry WHERE execution_id = $executionId AND metric_name = 'bot_hours'` — use Drizzle `sum()` on telemetry.metricValue.
3. **Total cost**: `SELECT COALESCE(SUM(amount_cents), 0) FROM billing_events WHERE execution_id = $executionId AND event_type = 'tool_invoked'` — use Drizzle `sum()` on billingEvents.amountCents.
4. **Average bot score**: `SELECT AVG(composite_score::numeric) FROM bots WHERE execution_id = $executionId AND composite_score IS NOT NULL` — use Drizzle `avg()`.
5. **Top bot**: `SELECT id FROM bots WHERE execution_id = $executionId ORDER BY composite_score DESC NULLS LAST LIMIT 1` — use Drizzle `orderBy(desc(bots.compositeScore))` with `.limit(1)`.
6. **Error distribution**:
   - Task failures: `SELECT COUNT(*) FROM tasks WHERE execution_id = $executionId AND status = 'failed'`.
   - Tool rejections: `SELECT COUNT(*) FROM tool_invocations WHERE execution_id = $executionId AND rejected = true`.
   - Return as `{ task_failures: N, tool_rejections: M }`.
7. **Task counts**: `SELECT COUNT(*) FROM tasks WHERE execution_id = $executionId` (total), and status-specific counts for completed/failed.
8. **Cost per task**: `totalCostCents / completedTasks`. Guard: if `completedTasks === 0`, return 0.

All monetary values remain integer cents (existing project convention). `totalBotHours` is a float from telemetry (matching bot_hours metric precision).

```typescript
// GET /executions/:id/report — execution summary report (PERF-06)
fastify.get('/:id/report', {
  schema: {
    params: Type.Object({
      id: Type.String({ format: 'uuid' }),
    }),
    response: {
      200: Type.Object({
        executionId: Type.String({ format: 'uuid' }),
        totalBots: Type.Integer(),
        totalBotHours: Type.Number(),
        totalCostCents: Type.Integer(),
        averageBotScore: Type.Number(),
        topPerformingBotId: Type.Union([Type.String({ format: 'uuid' }), Type.Null()]),
        errorDistribution: Type.Record(Type.String(), Type.Integer()),
        costPerTaskCents: Type.Integer(),
        totalTasks: Type.Integer(),
        completedTasks: Type.Integer(),
        failedTasks: Type.Integer(),
      }),
      404: Type.Object({ error: Type.String() }),
    },
  },
}, async (request, reply) => {
  const { id } = request.params;
  const execution = await getExecution(id);
  if (!execution) {
    return reply.code(404).send({ error: 'Execution not found' });
  }
  const report = await buildExecutionReport(id);
  return reply.code(200).send(report);
});
```

```typescript
// GET /executions/:id/leaderboard — bot leaderboard sorted by score (PERF-07)
fastify.get('/:id/leaderboard', {
  schema: {
    params: Type.Object({
      id: Type.String({ format: 'uuid' }),
    }),
    response: {
      200: Type.Array(
        Type.Object({
          botId: Type.String({ format: 'uuid' }),
          compositeScore: Type.Union([Type.Number(), Type.Null()]),
          tier: Type.Union([Type.String(), Type.Null()]),
          tasksCompleted: Type.Integer(),
          tasksFailed: Type.Integer(),
          botHours: Type.Union([Type.Number(), Type.Null()]),
        }),
      ),
      404: Type.Object({ error: Type.String() }),
    },
  },
}, async (request, reply) => {
  const { id } = request.params;
  const execution = await getExecution(id);
  if (!execution) {
    return reply.code(404).send({ error: 'Execution not found' });
  }

  // Get bots sorted by composite_score descending
  const botRows = await db
    .select({
      botId: bots.id,
      compositeScore: bots.compositeScore,
      tier: bots.tier,
    })
    .from(bots)
    .where(eq(bots.executionId, id))
    .orderBy(sql`${bots.compositeScore} DESC NULLS LAST`);

  // For each bot, get task counts and bot-hours
  const leaderboard = await Promise.all(
    botRows.map(async (bot) => {
      const [completedRow] = await db
        .select({ count: sql<number>`cast(count(*) as int)` })
        .from(tasks)
        .where(and(eq(tasks.claimedByBotId, bot.botId), eq(tasks.status, 'completed')));

      const [failedRow] = await db
        .select({ count: sql<number>`cast(count(*) as int)` })
        .from(tasks)
        .where(and(eq(tasks.claimedByBotId, bot.botId), eq(tasks.status, 'failed')));

      const [hoursRow] = await db
        .select({ value: telemetry.metricValue })
        .from(telemetry)
        .where(and(eq(telemetry.botId, bot.botId), eq(telemetry.metricName, 'bot_hours')));

      return {
        botId: bot.botId,
        compositeScore: bot.compositeScore ? Number(bot.compositeScore) : null,
        tier: bot.tier,
        tasksCompleted: completedRow?.count ?? 0,
        tasksFailed: failedRow?.count ?? 0,
        botHours: hoursRow?.value ? Number(hoursRow.value) : null,
      };
    }),
  );

  return reply.code(200).send(leaderboard);
});
```

Note: The leaderboard enrichment queries are N+1 per bot. This is acceptable for MVP where executions have at most 20 bots (maxBots cap). A production optimization would use a single JOIN or subquery. Do NOT prematurely optimize.

Ensure `and`, `eq`, `desc`, `sql` are imported from `drizzle-orm`. Add `telemetry` to the imports from `@claw/db` if not already present.
