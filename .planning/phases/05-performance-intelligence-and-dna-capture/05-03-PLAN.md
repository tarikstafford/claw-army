**Part A: Derive objective_category.**

Helper function `deriveObjectiveCategory(objective: string): string`:
- Take the execution's `objective` text.
- Lowercase it, replace non-alphanumeric chars with hyphens, collapse consecutive hyphens, trim hyphens from ends.
- Take the first 5 words (split by hyphen), rejoin with hyphens.
- Truncate to 255 chars (varchar limit on dna_store.objective_category).
- Example: "Summarize these research documents about climate change" -> "summarize-these-research-documents-about"

**Part B: Identify elite bots (DNA-01).**

Three configurable thresholds (env vars with defaults):
- `DNA_ELITE_THRESHOLD` — default: 75 (composite score minimum)
- `DNA_ABOVE_AVERAGE_PCT` — default: 20 (composite must exceed execution average by this %)
- `DNA_ERROR_RATE_CEILING` — default: 0.10 (error rate must be below this)

Logic:
1. Query execution objective: `SELECT objective FROM executions WHERE id = $executionId`.
2. Query all bots with scores: `SELECT id, composite_score FROM bots WHERE execution_id = $executionId AND composite_score IS NOT NULL`.
3. Compute execution average score: `AVG(composite_score)` from the fetched bots.
4. For each bot, re-compute error_rate from metrics-computer (or query it). Simplest: query `tasks` table for the bot — `failed / (completed + failed)`. If `completed + failed === 0`, error_rate = 0.
5. A bot is elite if ALL THREE conditions are met:
   - `composite_score > DNA_ELITE_THRESHOLD`
   - `composite_score > executionAvgScore * (1 + DNA_ABOVE_AVERAGE_PCT / 100)`
   - `error_rate < DNA_ERROR_RATE_CEILING`
6. Log how many elite bots were identified: `[dna-capture] Found ${eliteBots.length} elite bots out of ${allBots.length}`.

**Part C: Extract PII-safe DNA (DNA-02, DNA-04).**

For each elite bot, extract DNA fields from `tool_invocations`:

```typescript
// Query tool invocations ordered by time
const invocations = await db
  .select({
    toolName: toolInvocations.toolName,
    durationMs: toolInvocations.durationMs,
    totalTokens: toolInvocations.totalTokens,
    promptTokens: toolInvocations.promptTokens,
    completionTokens: toolInvocations.completionTokens,
    requestSummary: toolInvocations.requestSummary,
  })
  .from(toolInvocations)
  .where(and(
    eq(toolInvocations.botId, botId),
    eq(toolInvocations.rejected, false),
  ))
  .orderBy(toolInvocations.invokedAt);
```

Build `DnaPayload` (imported from `@claw/db`):

1. **systemPromptTemplate**: A structural descriptor, NOT actual prompts. Set to `"reasoning-loop-v1"` — the template name, not content. This is a structural pattern identifier.

2. **toolCallSequence**: `invocations.map(inv => inv.toolName)` — ordered list of tool names used. PII-safe (tool names are predefined strings: llm_call, fetch_url, write_file).

3. **argumentPatterns**: Extract only the **keys** of request_summary, never values. For each unique tool name, collect the set of argument keys seen across invocations:
   ```typescript
   const argPatterns: Record<string, string[]> = {};
   for (const inv of invocations) {
     const summary = inv.requestSummary as Record<string, unknown> | null;
     if (summary && typeof summary === 'object') {
       const toolKey = inv.toolName;
       if (!argPatterns[toolKey]) argPatterns[toolKey] = [];
       const keys = Object.keys(summary);
       // Only add unique keys
       for (const key of keys) {
         if (!argPatterns[toolKey]!.includes(key)) {
           argPatterns[toolKey]!.push(key);
         }
       }
     }
   }
   ```
   **CRITICAL: Extract ONLY keys, NEVER values from requestSummary. Values may contain PII or raw LLM output.**

4. **retryStrategy**: Query retry counts from tasks:
   ```typescript
   const taskRetries = await db
     .select({
       attemptCount: tasks.attemptCount,
       status: tasks.status,
     })
     .from(tasks)
     .where(eq(tasks.claimedByBotId, botId));

   const retryStrategy = {
     totalTasks: taskRetries.length,
     retriedTasks: taskRetries.filter(t => t.attemptCount > 1).length,
     maxAttempts: Math.max(...taskRetries.map(t => t.attemptCount), 0),
     avgAttempts: taskRetries.length > 0
       ? taskRetries.reduce((sum, t) => sum + t.attemptCount, 0) / taskRetries.length
       : 0,
   };
   ```

5. **timingProfile**: Aggregate duration_ms from tool invocations:
   ```typescript
   const durations = invocations.filter(i => i.durationMs != null).map(i => i.durationMs!);
   const timingProfile = {
     totalDurationMs: durations.reduce((s, d) => s + d, 0),
     avgDurationMs: durations.length > 0 ? durations.reduce((s, d) => s + d, 0) / durations.length : 0,
     minDurationMs: durations.length > 0 ? Math.min(...durations) : 0,
     maxDurationMs: durations.length > 0 ? Math.max(...durations) : 0,
     callCount: durations.length,
   };
   ```

6. **tokenDistribution**: Aggregate token counts by tool name:
   ```typescript
   const tokenDist: Record<string, { total: number; prompt: number; completion: number; count: number }> = {};
   for (const inv of invocations) {
     const key = inv.toolName;
     if (!tokenDist[key]) tokenDist[key] = { total: 0, prompt: 0, completion: 0, count: 0 };
     tokenDist[key]!.total += inv.totalTokens ?? 0;
     tokenDist[key]!.prompt += inv.promptTokens ?? 0;
     tokenDist[key]!.completion += inv.completionTokens ?? 0;
     tokenDist[key]!.count += 1;
   }
   ```

**Part D: Store versioned DNA record (DNA-03).**

For each elite bot:
1. Get next version: `SELECT COALESCE(MAX(version), 0) FROM dna_store WHERE bot_id = $botId AND objective_category = $category`.
2. Insert: `db.insert(dnaStore).values({ botId, executionId, objectiveCategory, version: nextVersion + 1, compositeScore: compositeScore.toFixed(2), dnaPayload })`.
3. Always INSERT, never UPDATE — each capture is a new versioned record.

Log each capture: `[dna-capture] Captured DNA for bot ${botId} (v${nextVersion + 1}, category: ${category})`.
