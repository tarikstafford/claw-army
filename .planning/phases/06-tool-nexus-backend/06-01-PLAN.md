      status TEXT NOT NULL DEFAULT 'connected',

    CREATE INDEX IF NOT EXISTS idx_tool_invocation_logs_connection ON tool_invocation_logs(connection_id);
    CREATE INDEX IF NOT EXISTS idx_tool_invocation_logs_user ON tool_invocation_logs(user_id);
    CREATE INDEX IF NOT EXISTS idx_tool_invocation_logs_created ON tool_invocation_logs(created_at DESC);

    Routes to implement:

    **GET /** — List all connections for a user. Query param `userId` (required).
    Returns array of connections with encrypted fields OMITTED. Include: id, userId, toolId, connectionType, status, displayLabel, tokenExpiresAt, scopes, lastUsedAt, createdAt, updatedAt.

    **POST /** — Create a new connection. Body:
    ```json
    {
      "userId": "string (required)",
      "toolId": "string (required)",
      "connectionType": "'oauth' | 'api_key' (required)",
      "accessToken": "string (for oauth)",
      "refreshToken": "string (for oauth)",
      "apiKey": "string (for api_key)",
      "displayLabel": "string (optional)",
      "tokenExpiresAt": "ISO string (optional)",
      "scopes": "string (optional)"
    }
    ```
    - For oauth: encrypt accessToken and refreshToken using encryptCredential, store ciphertext/iv/tag fields
    - For api_key: encrypt apiKey using encryptCredential, store ciphertext/iv/tag fields. Auto-generate displayLabel as masked key: `${apiKey.slice(0,4)}...${apiKey.slice(-4)}`
    - Return 201 with connection record (encrypted fields omitted)
    - Return 409 if (userId, toolId) already exists

    **DELETE /:id** — Soft delete by setting status to 'disconnected', or hard delete the row. Use hard delete for simplicity.
    - Return 200 `{ ok: true }` or 404 `{ error: 'Connection not found' }`

    **PATCH /:id/refresh** — Update OAuth tokens after refresh. Body:
    ```json
    {
      "accessToken": "string (required)",
      "refreshToken": "string (optional)",
      "tokenExpiresAt": "ISO string (optional)"
    }
    ```
    - Re-encrypt new tokens
    - Update status to 'connected' (clears any 'expired' state)
    - Return 200 with updated connection (encrypted fields omitted)

    **POST /:id/test** — Test connection. For now, just verify decryption works and return success.
    - Decrypt the stored credential (access token for OAuth, API key for API key connections)
    - If decryption succeeds, update lastUsedAt and return 200 `{ success: true, toolId, connectionType }`
    - If decryption fails, update status to 'errored' and return 200 `{ success: false, error: 'Credential decryption failed' }`

    **GET /:id/logs** — Get invocation logs for a connection. Returns latest 100 rows from tool_invocation_logs where connectionId matches, ordered by createdAt DESC.

    Error handling: wrap each route handler body in try/catch, return `{ error: (err as Error).message }` with 500.
