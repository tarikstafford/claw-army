    1. **`packages/plugins/akasa-tool-nexus/src/connectors/hubspot.ts`:**

    ```typescript
    import type { PluginContext, ToolResult } from '@paperclipai/plugin-sdk';
    import { TOOL_NAMES } from '../constants.js';
    import { logInvocation } from '../services/invocation-logger.js';

    export async function registerHubSpotTools(ctx: PluginContext): Promise<void> { ... }
    ```

    Tools:
    - `hubspot:create-contact`: POST to `https://api.hubapi.com/crm/v3/objects/contacts` with Bearer token from secrets. Body: `{ properties: { email, firstname, lastname, phone, company } }`. Return created contact ID and email.
    - `hubspot:search-contacts`: POST to `https://api.hubapi.com/crm/v3/objects/contacts/search` with `{ filterGroups: [{ filters: [{ propertyName: 'email', operator: 'CONTAINS_TOKEN', value: query }] }], limit }`. Return array of `{ id, email, firstName, lastName }`.
    - `hubspot:create-deal`: POST to `https://api.hubapi.com/crm/v3/objects/deals` with `{ properties: { dealname, amount, dealstage } }`. Return deal ID and name.

    Secret key for HubSpot: resolve via `ctx.secrets.resolve('hubspot-api-key')`. If secret not found, return `{ error: 'HubSpot API key not configured. Add a secret named hubspot-api-key.' }`.
