```typescript
export interface OAuthProviderConfig {
  authorizeUrl: string;
  tokenUrl: string;
  scopes: string[];
  clientIdEnv: string;
  clientSecretEnv: string;
}
```

Three entries in `OAUTH_PROVIDERS`:

- `hubspot`: authorizeUrl `https://app.hubspot.com/oauth/authorize`, tokenUrl `https://api.hubapi.com/oauth/v1/token`, scopes `['crm.objects.contacts.read', 'crm.objects.contacts.write', 'crm.objects.deals.read', 'crm.objects.deals.write']`, clientIdEnv `HUBSPOT_CLIENT_ID`, clientSecretEnv `HUBSPOT_CLIENT_SECRET`
- `slack`: authorizeUrl `https://slack.com/oauth/v2/authorize`, tokenUrl `https://slack.com/api/oauth.v2.access`, scopes `['chat:write', 'channels:read']`, clientIdEnv `SLACK_CLIENT_ID`, clientSecretEnv `SLACK_CLIENT_SECRET`
- `google-sheets`: authorizeUrl `https://accounts.google.com/o/oauth2/v2/auth`, tokenUrl `https://oauth2.googleapis.com/token`, scopes `['https://www.googleapis.com/auth/spreadsheets']`, clientIdEnv `GOOGLE_CLIENT_ID`, clientSecretEnv `GOOGLE_CLIENT_SECRET`. Also add `access_type=offline&prompt=consent` as extra authorize params so Google returns a refresh_token.

Export a helper `function getOAuthProvider(toolId: string): OAuthProviderConfig | undefined` that does a lookup on `OAUTH_PROVIDERS`.

**2. Create `services/akasa-server/src/routes/oauth-flow.ts`:**

Export `function oauthFlowRouter(): Router` that creates an Express Router with two routes:

**GET `/oauth/:toolId/start`:**
- Read `userId` from query param (required, return 400 if missing).
- Read `redirectUri` from query param (optional — defaults to `${process.env['AKASA_BASE_URL'] ?? 'http://localhost:5173'}/tools/callback`).
- Look up provider config via `getOAuthProvider(req.params.toolId)`. Return 404 `{ error: 'Unknown OAuth provider: <toolId>' }` if not found.
- Read `clientId` from `process.env[provider.clientIdEnv]`. Return 500 `{ error: 'OAuth not configured for <toolId>' }` if missing.
- Generate a `state` parameter by base64url-encoding `JSON.stringify({ userId, toolId, redirectUri })`. (This is an internal-only server; CSRF protection via session is not needed yet but state carries the context for the callback.)
- Build the authorization URL: `${provider.authorizeUrl}?response_type=code&client_id=${clientId}&redirect_uri=${redirectUri}&scope=${provider.scopes.join(' ')}&state=${state}`. For google-sheets, also append `&access_type=offline&prompt=consent`.
- Redirect (302) to the built URL.

**GET `/oauth/:toolId/callback`:**
- Read `code` and `state` from query params. Return 400 if `code` is missing.
- Decode `state` from base64url JSON to get `{ userId, toolId, redirectUri }`. Return 400 if decode fails.
- Look up provider config via `getOAuthProvider(toolId)`. Return 404 if not found.
- Read `clientId` from `process.env[provider.clientIdEnv]` and `clientSecret` from `process.env[provider.clientSecretEnv]`. Return 500 if either is missing.
- POST to `provider.tokenUrl` with `application/x-www-form-urlencoded` body: `grant_type=authorization_code`, `code`, `client_id`, `client_secret`, `redirect_uri`.
- Parse response JSON. For Slack, check `data.ok === true` and use `data.access_token ?? data.authed_user?.access_token`. For HubSpot/Google, read `access_token`, `refresh_token`, `expires_in` directly.
- Encrypt `accessToken` via `encryptCredential(accessToken)`. If `refreshToken` exists, encrypt it too.
- Upsert into `toolConnections` table: first try `db.insert(toolConnections).values({...}).returning()`. On unique constraint violation (catch error with message containing 'unique' or 'duplicate' or 'UNIQUE'), do `db.update(toolConnections).set({...}).where(and(eq(toolConnections.userId, userId), eq(toolConnections.toolId, toolId))).returning()` instead.
- Insert values: `userId`, `toolId`, `connectionType: 'oauth'`, `status: 'connected'`, encrypted access token fields (`encryptedAccessToken`, `tokenIv`, `tokenTag`, `keyVersion`), encrypted refresh token fields if present (`encryptedRefreshToken`, `refreshIv`, `refreshTag`), `tokenExpiresAt` computed from `expires_in` (new Date(Date.now() + expires_in * 1000)), `scopes` as the joined scope string, `displayLabel` as `'OAuth: <toolId>'`.
- On success, redirect (302) to `${process.env['AKASA_BASE_URL'] ?? 'http://localhost:5173'}/tools?connected=${toolId}`.
- On token exchange failure, redirect to `${process.env['AKASA_BASE_URL'] ?? 'http://localhost:5173'}/tools?error=oauth_failed&tool=${toolId}`.
- Wrap all async operations in try/catch, pass errors to `next(err)`.
