Create `services/akasa-server/src/routes/evolution-dashboard.ts` exporting `evolutionDashboardRouter()` that returns a Router with 6 GET routes:

1. **GET /fleet** — Fleet overview (DASH-01):
   - Query `agentClasses` grouped by `currentClass` using `db.select({ currentClass: agentClasses.currentClass, rowCount: count() }).from(agentClasses).groupBy(agentClasses.currentClass)`
   - Query `councilVerdicts` WHERE `requiresHumanConfirmation = true AND status = 'pending'` for pending count
   - Query `bots` with `compositeScore IS NOT NULL` to compute average
   - Return JSON: `{ classCounts: { Novice: N, Understudy: N, Artisan: N, Retired: N }, totalBots: N, averageCompositeScore: string | null, pendingVerdictCount: N }`
   - Initialize classCounts with 0 for all four classes, then fill from query results

2. **GET /bots/:botId/timeline** — Per-bot timeline (DASH-02):
   - Query `councilVerdicts` WHERE `botId = req.params.botId`, select id, verdictType, status, weightedConfidenceScore, verdictSummary, createdAt
   - Query `agentClasses` WHERE `botId = req.params.botId AND lastTransitionAt IS NOT NULL`, select id, currentClass, lastTransitionAt, taskCategory
   - Query `dnaStore` WHERE `botId = req.params.botId`, select id, objectiveCategory, compositeScore, capturedAt
   - Map each to `TimelineEvent { id, type: 'verdict'|'class_transition'|'dna_capture', timestamp, summary, verdictType?, status?, newClass?, compositeScore? }`
   - Merge all three arrays, sort by timestamp DESC
   - Return JSON array

3. **GET /bots/:botId/lineage** — Soul lineage walk (DASH-03):
   - Get the bot's current `soulId` from `bots` table WHERE `id = req.params.botId`
   - Walk `botSouls.parentSoulId` chain starting from soulId, max depth 10
   - For each soul: select id, parentSoulId, isArchetype, archetypeName, generation, contentHash
   - Build chain array, reverse it (root first)
   - Enrich: check `agentClasses.isPioneer` for this botId
   - Return as JSON array of `{ id, label, generation, isArchetype, isPioneer }` where label is `archetypeName ?? contentHash.slice(0, 8)`

4. **GET /bots/:botId/ledger** — Experiment ledger (DASH-04):
   - Query `councilVerdicts` WHERE `botId = req.params.botId` ORDER BY `createdAt ASC`
   - For each row, build `{ executionId, executionDate: createdAt, compositeScore: weightedConfidenceScore, scoreDelta, verdictType, status }`
   - Compute scoreDelta: iterate rows, keep `previousScore` variable (null for first). Delta = current - previous. First row gets `null` for delta.
   - Check if a `botSouls` row exists with this executionId to determine `mutationApplied: boolean`
   - Determine `keepDiscard`: if status === 'confirmed' and verdictType in ['Promote','Maintain'] then 'keep'; if status === 'confirmed' and verdictType in ['Demote','Retire'] then 'discard'; else 'pending'
   - Return JSON array

5. **GET /benchmarks** — Category benchmarks (DASH-05):
   - Query all `categoryBenchmarks` rows
   - Return JSON array with all fields: taskCategory, pioneerBotId, baselineCompositeScore, confirmedRunCount, thinDataFlag, benchmarkMature, createdAt

6. **GET /pending** — Pending human-confirmation verdicts (DASH-06):
   - Query `councilVerdicts` WHERE `requiresHumanConfirmation = true AND status = 'pending'` ORDER BY `createdAt DESC`
   - For each verdict, also query `bots` to get bot name/status context
   - Return JSON array with: id, botId, verdictType, verdictSummary, weightedConfidenceScore, performanceJudgeOutput, soulAnalystOutput, devilsAdvocateOutput, createdAt

Import pattern: `import { db } from '@claw/db';` and table exports from `@claw/db` (e.g. `import { agentClasses, councilVerdicts, botSouls, categoryBenchmarks, dnaStore, bots } from '@claw/db';`). Import `eq, and, desc, count, isNotNull, sql` from `drizzle-orm`.

All routes wrap handler body in try/catch with `next(err)` on error (same pattern as existing routes in council.ts, god-layer.ts).

export const load: PageServerLoad = async ({ fetch, parent }) => {

    ? await fleetRes.value.json()
    : null;
  const pendingVerdicts = pendingRes.status === 'fulfilled' && pendingRes.value.ok
    ? await pendingRes.value.json()
    : [];

  return { fleet, pendingVerdicts };
};
