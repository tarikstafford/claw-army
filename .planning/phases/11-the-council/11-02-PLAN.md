**2. Constants:**
```typescript
const COUNCIL_LOCK_DURATION_MS = 5 * 60 * 1000;  // 5 minutes — LLM calls take 30-90s
const COUNCIL_STALLED_INTERVAL_MS = 30_000;
const COUNCIL_MAX_STALLED_COUNT = 1;
const COUNCIL_CONCURRENCY = 5;                     // CNCL-01 requirement

// Verdict type numeric values for weighted average resolution
const VERDICT_VALUES: Record<string, number> = {
  Promote: 4,
  Maintain: 3,
  Monitor: 2,
  Demote: 1,
  Retire: 0,
};
const VERDICT_FROM_VALUE = ['Retire', 'Demote', 'Monitor', 'Maintain', 'Promote'] as const;
```

**3. `loadCouncilContext` function:**
```typescript
async function loadCouncilContext(executionId: string, botId: string, soulId: string | null): Promise<CouncilContext>
```
- Query `bots` table for the bot's metrics: `tasksClaimed`, `tasksCompleted`, `tasksFailed`, `compositeScore`, `tier`. Use `eq(bots.id, botId)`.
- If bot not found, throw `Bot ${botId} not found`.
- If `soulId` is not null, query `botSouls` where `eq(botSouls.id, soulId)` to get `soulContent`, `constitutionDirectives`, `taskCategory`. Parse `constitutionDirectives` from JSONB as `string[]` (it's stored as a JSON array of strings).
- Query `decisionTraces` where `eq(decisionTraces.executionId, executionId)` AND `eq(decisionTraces.botId, botId)`. Select `decisionId`, `decisionType`, `directiveReferenced`, `attributionConfidence`, `outcome`, `metadata`.
- Query `telemetry` where `eq(telemetry.executionId, executionId)` AND `eq(telemetry.botId, botId)`. Select `metricName`, `metricValue`.
- Assemble and return `CouncilContext`.

**4. `aggregateVerdicts` function:**
```typescript
function aggregateVerdicts(
  perf: PerformanceJudgeOutput,
  soul: SoulAnalystOutput,
  devil: DevilsAdvocateOutput,
): { verdictType: 'Promote' | 'Maintain' | 'Monitor' | 'Demote' | 'Retire'; weightedConfidenceScore: number; requiresHumanConfirmation: boolean; hasUnresolvedDevilsAdvocate: boolean; verdictSummary: string; }
```
- Compute weighted confidence score: `perf.confidence * 0.5 + soul.confidence * 0.35 + devil.confidence * 0.15` (CNCL-05).
- Compute weighted verdict type: convert each judge's verdictType to numeric value using `VERDICT_VALUES`, compute `perf_val * 0.5 + soul_val * 0.35 + devil_val * 0.15`, round to nearest integer, map back via `VERDICT_FROM_VALUE[rounded]`. Clamp to 0-4 range.
- `hasUnresolvedDevilsAdvocate = devil.strongUnresolvedArgument`.
- `requiresHumanConfirmation = hasUnresolvedDevilsAdvocate` (CNCL-05: strong DA argument escalates).
- Build `verdictSummary`: concatenate each judge's summary with a label prefix, separated by newlines. Format: `"Performance Judge: {perf.summary}\n\nSoul Analyst: {soul.summary}\n\nDevil's Advocate: {devil.summary}"`.

**5. `councilProcessor` function:**
```typescript
async function councilProcessor(job: Job<CouncilJobData>): Promise<void>
```
- Extract `{ executionId, botId, soulId }` from `job.data`.
- Set up lock extension interval: every 60 seconds, call `job.extendLock(job.token!, COUNCIL_LOCK_DURATION_MS)` (mirror openclaw-dispatcher pattern). Wrap in try-catch to avoid crashing on token expiry.
- Load context: `const context = await loadCouncilContext(executionId, botId, soulId)`.
- Run all three judges in parallel (CNCL-02):
  ```typescript
  const [performanceOutput, soulOutput, devilOutput] = await Promise.all([
    runPerformanceJudge(context),
    runSoulAnalyst(context),
    runDevilsAdvocate(context),
  ]);
  ```
- Aggregate: `const verdict = aggregateVerdicts(performanceOutput, soulOutput, devilOutput)`.
- Persist to `council_verdicts`:
  ```typescript
  await db.insert(councilVerdicts).values({
    executionId,
    botId,
    soulId,
    verdictType: verdict.verdictType,
    status: 'pending',
    weightedConfidenceScore: verdict.weightedConfidenceScore.toFixed(3),
    requiresHumanConfirmation: verdict.requiresHumanConfirmation,
    hasUnresolvedDevilsAdvocate: verdict.hasUnresolvedDevilsAdvocate,
    verdictSummary: verdict.verdictSummary,
    performanceJudgeOutput: performanceOutput,
    soulAnalystOutput: soulOutput,
    devilsAdvocateOutput: devilOutput,
  });
  ```
- Log disagreement rate (CNCL-04 health metric):
  ```typescript
  console.log('[council-worker] Verdict persisted:', {
    executionId, botId, verdictType: verdict.verdictType,
    confidence: verdict.weightedConfidenceScore.toFixed(3),
    requiresHumanConfirmation: verdict.requiresHumanConfirmation,
  });
  console.log('[council-worker] Soul Analyst counterfactual disagreement rate:', {
    executionId, botId, disagreementRate: (soulOutput.disagreementRate ?? 0).toFixed(3),
  });
  ```
- Clear the lock extension interval in a `finally` block.

**6. `startCouncilWorker` function:**
```typescript
export function startCouncilWorker(): Worker<CouncilJobData>
```
- Create `new Worker<CouncilJobData>(COUNCIL_QUEUE_NAME, councilProcessor, { ... })` with:

- Log: `console.log('[council-worker] Started (concurrency=5, rate-limit=10/min)')`.
- Return the worker.

   async function enqueueCouncilJobs(executionId: string): Promise<void> {
     const executionBots = await db
       .select({ id: bots.id, soulId: bots.soulId })
       .from(bots)
       .where(eq(bots.executionId, executionId));

     if (executionBots.length === 0) return;

     await councilQueue.addBulk(
