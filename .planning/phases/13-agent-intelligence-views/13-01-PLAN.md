**1. GET /bots/:botId/profile** (per D-01, D-02, D-04 — AGENT-01)

Query: `bots` LEFT JOIN `agentClasses` (on agentClasses.botId = bots.id) LEFT JOIN `botSouls` (on botSouls.id = bots.soulId).

Select these columns:
- From bots: `id`, `compositeScore`, `soulId`, `status`
- From agentClasses: `currentClass`, `isPioneer`, `taskCategory`, `lastTransitionAt`, `artisanGraduationAt`, `createdAt` (as classCreatedAt)
- From botSouls: `soulContent`, `dimensions`, `constitutionDirectives`, `generation`, `archetypeName`, `isArchetype`

Response shape:
```json
{
  "botId": "uuid",
  "compositeScore": "0.82",
  "status": "idle",
  "currentClass": "Understudy",
  "isPioneer": false,
  "taskCategory": "research",
  "archetypeName": "Cautious Verifier",
  "soulId": "uuid",
  "soulContent": "full SOUL.md text",
  "dimensions": { "identityRole": "...", "decisionPriorities": "...", "toolUsageDoctrine": "...", "riskTolerance": "...", "communicationStyle": "...", "recoveryBehavior": "...", "ethicalHardStops": "..." },
  "constitutionDirectives": ["directive1", "directive2"],
  "generation": 3,
  "classHistory": [
    { "class": "Novice", "transitionAt": "2026-03-24T...", "category": "research" }
  ]
}
```

For `classHistory`, query `agentClasses` for the single row matching botId (there is one row per bot+category, so classHistory is derived from the single row: include an entry for the initial class creation (createdAt, "Novice") and if lastTransitionAt is non-null add an entry for the current class). This is a simplified class history since individual transitions are not stored — just the initial and current state.

If bot not found, return 404: `res.status(404).json({ error: 'Bot not found' })`.
If bot has no soulId, return null for soul-related fields (soulContent, dimensions, constitutionDirectives, generation, archetypeName).

**Import:** At the top of the file, add the lazy import pattern for Paperclip DB (same pattern as evolution-trigger.ts):
```typescript
// Lazy import to avoid circular initialization
let paperclipDb: ReturnType<typeof import('@paperclipai/db')['createDb']> | null = null;
async function getPaperclipDb() {
  if (!paperclipDb) {
    const { createDb } = await import('@paperclipai/db');
    paperclipDb = createDb(process.env.DATABASE_URL!);
  }
  return paperclipDb;
}
```

Also dynamically import `agentRuntimeState` from `@paperclipai/db` inside the route handler (or alongside createDb in getPaperclipDb).

**Endpoint logic:**

1. Look up `bots.paperclipAgentId` from the Akasa `bots` table using `botId` param
2. If bot not found or `paperclipAgentId` is null, return `res.json(null)` with 200 status (graceful degradation per D-21)
3. Query `agentRuntimeState` from Paperclip's shared DB using `paperclipAgentId` as the primary key
4. If no runtime state row found, return `res.json(null)` with 200 status
5. Return the runtime state:

```json
{
  "sessionId": "string | null",
  "lastRunStatus": "string | null",
  "totalInputTokens": 12400,
  "totalOutputTokens": 3200,
  "totalCachedInputTokens": 800,
  "totalCostCents": 142,
  "lastError": "string | null",
  "updatedAt": "2026-04-07T..."
}
```

Wrap entire handler in try/catch, call `next(err)` on error — consistent with all other handlers in the file.

**Important:** The `agentRuntimeState` table uses `agentId` as primary key (UUID matching Paperclip's `agents.id`). The bridge is `bots.paperclipAgentId`. Always resolve through this bridge field.
