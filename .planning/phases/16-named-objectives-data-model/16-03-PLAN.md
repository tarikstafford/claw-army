<objective>
Link executions to objectives by accepting an optional `objectiveId` in the POST /executions endpoint and persisting it as the FK on the execution row -- enabling the launch-from-objective flow (OBJ-02).

Purpose: This wires the execution creation path to the objectives data model. When a user launches a run from a saved objective, the UI sends the objectiveId along with the (potentially overridden) settings, and the execution is linked back to that objective for history tracking.
Output: Updated execution creation flow that optionally links to an objective.
</objective>
