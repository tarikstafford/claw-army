  <action>
Create `services/ui/src/routes/objectives/+page.svelte` following the billing/+page.svelte pattern (Svelte 5 runes, $effect with browser guard, loading/error states).

**Script section:**
- Import `browser` from `$app/environment`
- Import `getObjectives` from `$lib/api`
- Import `ObjectiveListItem` type from `$lib/types`
- State: `objectives = $state<ObjectiveListItem[]>([])`, `loading = $state(true)`, `error = $state<string | null>(null)`
- `$effect(() => { if (!browser) return; getObjectives().then(data => { objectives = data; loading = false; }).catch(err => { error = (err as Error).message; loading = false; }); });`

**Template section:**
- `<svelte:head><title>Objectives | Claw Army</title></svelte:head>`
- Page container with `.page` class (max-width: 1000px, matching billing)
- `<h1>Objectives</h1>` with subtitle: "Your saved objectives and their run history."
- Loading state: `{#if loading}<div class="loading">Loading...</div>{:else if error}<div class="error">{error}</div>{:else}...{/if}`
- Empty state: `{#if objectives.length === 0}<p class="empty">No objectives yet. Create one from the Deploy Crew page.</p>{:else}...{/if}`
- Objectives rendered as a table (matching the billing execution history table pattern):
  - Columns: Name, Last Run, Runs, Total Spend, Best Class
  - Each row is clickable via `<a href="/objectives/{obj.id}">` on the name column
  - Name column: `{obj.name}` (truncate to 50 chars with ellipsis if longer)
  - Last Run column: status badge using `<span class="status status-{obj.lastRunStatus}">{obj.lastRunStatus}</span>` or "No runs" if null
  - Runs column: `{obj.runCount}`
  - Total Spend column: `${(obj.totalSpendCents / 100).toFixed(2)}` right-aligned
  - Best Class column: `<span class="class-badge class-{obj.bestBotClass?.toLowerCase()}">{obj.bestBotClass}</span>` or "---" if null

**Style section:**
- Reuse the exact same `.page`, `h1`, `.subtitle`, `.loading`, `.error`, `.empty`, `.table-wrapper`, `table`, `thead th`, `tbody td`, `tbody tr:nth-child(even)`, `tbody tr:hover`, `.status`, `.status-*` styles from billing/+page.svelte
- Add class badge styles:
  - `.class-badge`: inline-block, padding 0.2rem 0.6rem, border-radius 9999px, font-size 0.75rem, font-weight 700, text-transform uppercase
  - `.class-novice`: color #6b7280, background #f3f4f6, border 1px solid #e5e7eb
  - `.class-understudy`: color #7c3aed, background #f5f3ff, border 1px solid #ddd6fe
  - `.class-artisan`: color #d97706, background #fffbeb, border 1px solid #fde68a
  - `.class-retired`: color #9ca3af, background #f9fafb, border 1px solid #e5e7eb

Use the dark-theme CSS variables from app.css (var(--surface-1), var(--border), var(--text-primary), var(--text-secondary), var(--text-muted)) consistently. The billing page uses hardcoded light-mode colors -- follow that same pattern for consistency with the existing codebase rather than converting to CSS variables (to avoid visual inconsistency with other pages).
