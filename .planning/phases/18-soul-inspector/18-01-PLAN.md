**Backend — new `GET /:botId/soul` endpoint in `bots.ts`:**

Add a new route handler BEFORE the existing `/:botId/detail` handler. Import `botSouls`, `councilVerdicts`, `agentClasses` from `@claw/db` and `desc`, `inArray` from `drizzle-orm` (extend existing imports).

The endpoint performs 4 queries:
1. Get bot record: `db.select({ soulId: bots.soulId }).from(bots).where(eq(bots.id, botId))`. If no bot found, return 404 `{ error: 'Bot not found' }`.
2. If `bot.soulId` is non-null, get soul data: `db.select().from(botSouls).where(eq(botSouls.id, bot.soulId))`. Extract `soulContent`, `generation`, `parentSoulId`, `isArchetype`, `taskCategory`, `constitutionDirectives`, `dimensions`.
3. Get most recent council verdict: `db.select({ verdictType, weightedConfidenceScore, verdictSummary, soulAnalystOutput, performanceJudgeOutput }).from(councilVerdicts).where(eq(councilVerdicts.botId, botId)).orderBy(desc(councilVerdicts.createdAt)).limit(1)`. Cast `Number(verdictRow.weightedConfidenceScore)` to avoid PG numeric-as-string (decision [17-01]).
4. Get best agent class using CLASS_RANK precedence map: `{ Artisan: 3, Understudy: 2, Novice: 1, Retired: 0 }`. Query `db.select({ currentClass: agentClasses.currentClass }).from(agentClasses).where(eq(agentClasses.botId, botId))`, iterate rows to find highest rank. This is the exact pattern from `executions.ts` leaderboard handler (lines 419-443).

Return 200 with all fields. If soulId is null, return soulContent/generation/parentSoulId/etc. as null (NOT 404 — the bot exists even without a soul).

TypeBox response schema:
- `soulId`: `Type.Union([Type.String({ format: 'uuid' }), Type.Null()])`
- `soulContent`: `Type.Union([Type.String(), Type.Null()])`
- `generation`: `Type.Union([Type.Integer(), Type.Null()])`
- `parentSoulId`: `Type.Union([Type.String({ format: 'uuid' }), Type.Null()])`
- `isArchetype`: `Type.Union([Type.Boolean(), Type.Null()])`
- `taskCategory`: `Type.Union([Type.String(), Type.Null()])`
- `constitutionDirectives`: `Type.Union([Type.Array(Type.String()), Type.Null()])`
- `dimensions`: `Type.Union([Type.Unknown(), Type.Null()])` (7-dimension JSONB)
- `agentClass`: `Type.Union([Type.Literal('Novice'), Type.Literal('Understudy'), Type.Literal('Artisan'), Type.Literal('Retired'), Type.Null()])`
- `verdict`: `Type.Union([Type.Object({ verdictType: Type.String(), weightedConfidenceScore: Type.Number(), verdictSummary: Type.String(), soulAnalystOutput: Type.Unknown(), performanceJudgeOutput: Type.Unknown() }), Type.Null()])`

Also include the 401 response code in the response schema (decision [16-02] — TypeBox auth-protected routes must declare 401): `401: Type.Object({ error: Type.String() })`.

**Create `SoulInspectorPanel.svelte` in `services/ui/src/lib/components/`:**

This is a new directory — create it. The component is a CSS slide-in drawer (right side, `position: fixed`, 480px max-width). Uses Svelte 5 `$props()` (NOT `export let`), `$state()`, and `$effect()`.

Props: `{ botId: string | null; onClose: () => void }`

State: `soul: BotSoul | null`, `loading: boolean`, `error: string | null`

Data loading: `$effect(() => { ... })` — when `botId` changes and is non-null, call `getBotSoul(botId)`. Import `browser` from `$app/environment` and guard with `if (!browser || !botId)`. On success set `soul`; on error set `error`. Reset `soul = null` when botId becomes null.

Render when `botId` is non-null:
1. **Backdrop overlay** — fixed, inset 0, semi-transparent black, `onclick={onClose}`, `role="presentation"`.
2. **Panel aside** — fixed right, sliding in with CSS `@keyframes slideIn` from `translateX(100%)`. Set `tabindex="-1"` for focus management. Auto-focus on open via `$effect(() => { if (botId && panelRef) panelRef.focus(); })` with `bind:this={panelRef}`.
3. **Close button** — "x" in top-right corner, calls `onClose`.
4. **Loading state** — show "Loading soul data..." text when loading.
5. **Error state** — show error message in red.
6. **No soul state** — if `soul` loaded but `soul.soulId` is null, show "No soul data available for this bot" in muted text.
7. **Soul content sections** (when soul data exists):
   - **Agent class badge** — show `soul.agentClass` if non-null (reuse tier badge colors: Novice=#3b82f6, Understudy=#8b5cf6, Artisan=#d97706, Retired=#6b7280).
   - **Lineage section** — Generation: `soul.generation` (or "N/A"). Parent: `soul.parentSoulId ? soul.parentSoulId.slice(0, 8) + '...' : 'Seed Soul'`. Category: `soul.taskCategory ?? 'Unknown'`. Archetype: `soul.isArchetype ? 'Yes' : 'No'`.
   - **Behavioral Dimensions** — render `soul.dimensions` as 7 labeled sections: "Identity & Role", "Decision Priorities", "Tool Usage Doctrine", "Risk Tolerance", "Communication Style", "Recovery Behavior", "Ethical Hard Stops". Use `<h4>` for each heading and `<p>` with `white-space: pre-wrap` for content. If `dimensions` is null, show "Dimensions not available".
   - **Constitution Directives** — render `soul.constitutionDirectives` as a numbered list `<ol>`. If null, show "No directives".
   - **Council Verdict** (only if `soul.verdict` is non-null) — show verdict type (Promote/Retire as a colored badge), confidence score formatted as percentage (`(score * 100).toFixed(1)%`), verdict summary as paragraph. Below that, expandable per-judge sections for `soulAnalystOutput` and `performanceJudgeOutput` — render each as a JSON-like summary. Use the verdict detail rendering pattern from `verdicts/[verdictId]/+page.svelte` as reference: show `.verdict`, `.summary`, and key details.

CSS: Use hardcoded light-mode colors consistent with the execution monitoring pages (NOT CSS variables — per decision [17-02]). Inspector panel background `#fff`, text `#111827`, borders `#e5e7eb`. Section separators with `border-top: 1px solid #e5e7eb`.
