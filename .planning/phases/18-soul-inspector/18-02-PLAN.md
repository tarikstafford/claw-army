**Backend — extend `GET /bots/by-execution/:executionId` in `bots.ts`:**

This endpoint currently returns `{ id, status, tasksClaimed, tasksCompleted, tasksFailed, startedAt, errorMessage }` per bot. Extend it to also return `agentClass`.

1. Ensure `agentClasses` is imported from `@claw/db` and `inArray` from `drizzle-orm` (may already be imported by 18-01).

2. Add `agentClass` to the TypeBox response schema:
   ```typescript
   agentClass: Type.Union([
     Type.Literal('Novice'),
     Type.Literal('Understudy'),
     Type.Literal('Artisan'),
     Type.Literal('Retired'),
     Type.Null(),
   ]),
   ```

3. In the handler, after the existing `db.select().from(bots).where(...)` query, add a batch agent class lookup. Follow the exact pattern from `executions.ts` leaderboard handler (lines 419-443):

   ```typescript
   const botRows = await db.select({ ... }).from(bots).where(...).orderBy(...);
   const botIds = botRows.map(b => b.id);

   // Batch agent class lookup
   const CLASS_RANK: Record<string, number> = { Artisan: 3, Understudy: 2, Novice: 1, Retired: 0 };
   const agentClassMap = new Map<string, 'Novice' | 'Understudy' | 'Artisan' | 'Retired'>();

   if (botIds.length > 0) {
     const agentClassRows = await db
       .select({ botId: agentClasses.botId, currentClass: agentClasses.currentClass })
       .from(agentClasses)
       .where(inArray(agentClasses.botId, botIds));
     for (const row of agentClassRows) {
       const existing = agentClassMap.get(row.botId);
       if (!existing || (CLASS_RANK[row.currentClass] ?? -1) > (CLASS_RANK[existing] ?? -1)) {
         agentClassMap.set(row.botId, row.currentClass as any);
       }
     }
   }

   return botRows.map(b => ({ ...b, agentClass: agentClassMap.get(b.id) ?? null }));
   ```

   The `if (botIds.length > 0)` guard prevents `inArray` from generating an empty IN clause (which is invalid SQL in PostgreSQL).
