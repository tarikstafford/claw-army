3. **Add a new $effect for loading pending verdicts** — fetch once on load and poll every 10 seconds (slower than bots since verdicts change less frequently):
   ```typescript
   $effect(() => {
     if (!browser) return;
     // Fetch immediately
     getExecutionPendingVerdicts(executionId).then(v => { pendingVerdicts = v; }).catch(() => {});

     const isTerminal =
       execution?.status === 'completed' ||
       execution?.status === 'failed' ||
       execution?.status === 'stopped';
     if (isTerminal) return;

     const interval = setInterval(() => {
       getExecutionPendingVerdicts(executionId).then(v => { pendingVerdicts = v; }).catch(() => {});
     }, 10000);

     return () => clearInterval(interval);
   });
   ```

   **Note:** This effect reads `execution?.status` to decide if polling should continue. Since `execution` is a separate `$state` set in a different effect, this is safe and does not create infinite re-runs (same pattern as the existing SSE effect).

4. **Add a helper function** to check if a bot has a pending verdict:
   ```typescript
   function getPendingVerdictForBot(botId: string): VerdictDetail | undefined {
     return pendingVerdicts.find(v => v.botId === botId);
   ```
