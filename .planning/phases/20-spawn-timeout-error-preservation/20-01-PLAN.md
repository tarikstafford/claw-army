<objective>
Fix the spawn-timeout status overwrite bug: `stopBot()` unconditionally writes `status: 'stopped'` to the DB, overwriting the `status: 'failed'` and `errorMessage` that the spawn-timeout checker writes immediately before calling `stopBot()`. After this fix, timed-out bots remain `failed` with their error message intact so the UI can display the failure reason.

Purpose: Closes BOT-04 gap — timed-out bots were silently downgraded from `failed` to `stopped`, making spawn failures invisible in the UI.
Output: Modified `bot-orchestrator.ts` with `skipDbUpdate` option on `stopBot()`.
</objective>
