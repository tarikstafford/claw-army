  <name>Task 1: Restyle bot detail page to Akasa dark theme</name>
  <files>services/ui/src/routes/executions/[id]/bots/[botId]/+page.svelte</files>
  <action>
The bot detail page is 767 lines with approximately 70 hardcoded hex values. Apply a systematic token replacement across the entire `<style>` block and any inline styles in the template.

**Token mapping (apply to the full file):**

Page-level:
- Page background: `var(--bg)` or `var(--bg-2)`
- `<title>` tag: Change "Claw Army" to "Akasa" (e.g., `Bot {botId} | Akasa`)

Cards and panels:
- Card/panel backgrounds (`#fff`, `#ffffff`, `#f8f9fa`, `#f9fafb`) → `var(--bg-card)`
- Card borders (`#e5e7eb`, `#eee`, `#ddd`, `#e2e8f0`) → `var(--border)`
- Card hover border → `var(--border-mid)`
- Card border-radius → `14px` (Akasa standard)
- Card box-shadow → `0 2px 12px rgba(0,0,0,0.3)` (darker for dark theme)

Text:
- Primary text (`#111`, `#1a1a2e`, `#333`, `#1f2937`, `#374151`) → `var(--text)`
- Secondary text (`#555`, `#666`, `#6b7280`) → `var(--text-muted)`
- Labels/captions (`#888`, `#999`, `#9ca3af`, `#aaa`) → `var(--text-faint)`

Status/state colors:
- Active/running state (`#10b981`, `#059669`, green tones) → `var(--teal)`
- Error/failed state (`#ef4444`, `#dc2626`, red tones) → `var(--error)`
- Warning state (`#f59e0b`, `#d97706`, amber tones) → `var(--amber)`
- Idle/pending state → `var(--violet-bright)` or `var(--text-muted)`
- Stopped state → `var(--text-faint)`

Soul-specific:
- Artisan references → `var(--amber)` / `var(--amber-dim)`
- Understudy references → `var(--teal)` / `var(--teal-dim)`
- Novice references → `var(--text-muted)` / `rgba(236,232,255,0.05)`
- Retired references → `var(--rose)` / `var(--rose-dim)`
- Any SoulTierBadge usage should already work correctly (restyled in Plan 03)

Interactive elements:
- Buttons: `background: var(--violet); color: white;` with hover `opacity: 0.85`
- Links: `color: var(--violet-bright)` with hover `color: var(--violet-light)`
- Tabs/toggles: active tab `border-bottom: 2px solid var(--violet)`

Data display:
- Tables: header bg `var(--bg-3)`, row bg `var(--bg-card)`, border `var(--border)`
- Code/pre blocks: `background: var(--bg-2); font-family: var(--font-mono); color: var(--text)`
- Stat numbers: `font-family: var(--font-mono); color: var(--text)`

Section headers:
- Apply the Akasa eyebrow label pattern: `font-family: var(--font-mono); font-size: 10px; letter-spacing: 0.15em; text-transform: uppercase; color: var(--text-faint);`

Do NOT change any component logic, data fetching, event handlers, or TypeScript. Only CSS and inline styles.
