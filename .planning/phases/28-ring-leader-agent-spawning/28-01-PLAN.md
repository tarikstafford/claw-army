This is a NEW JWT module separate from the existing `orchestrator/jwt.ts` (which mints bot-level JWTs with only botId+executionId). The Ring Leader session JWT encodes agent-specific grants per SPAWN-01.

Define and export `SessionJwtPayload` interface:
```typescript
interface SessionJwtPayload {
  soulId: string;
  taskId: string;
  toolAllowlist: string[];
  thirdPartyGrants: string[];
  budgetAllocationCents: number;
  runtimeLimitSeconds: number;
  ringLeaderRunId: string;
}
```

Export `mintSessionJwt(payload: SessionJwtPayload): Promise<string>`:
- Use jose library (already in deps, same pattern as orchestrator/jwt.ts)
- HS256 algorithm, same BOT_JWT_SECRET env var (fall back to dev secret with console.warn, matching existing pattern in orchestrator/jwt.ts)
- Set subject to `session:${payload.soulId}:${payload.taskId}` for traceability
- Set expiration to payload.runtimeLimitSeconds + 300 seconds (5 min buffer)
- All SessionJwtPayload fields go into the JWT claims

Export `verifySessionJwt(token: string): Promise<SessionJwtPayload>`:
- jose.jwtVerify with HS256
- Extract and return typed SessionJwtPayload from payload
- Throw if any required field is missing

Use the same getJwtSecret() pattern from orchestrator/jwt.ts — read BOT_JWT_SECRET, warn on fallback. Do NOT import from orchestrator/jwt.ts (different concern, keep modules independent).

Create `agent-session-builder.ts` in services/execution-service/src/services/.

This module builds the full prompt string injected into each agent's OpenClaw session (the `input` field of POST /v1/responses). It combines SOUL.md + task brief + upstream intelligence into a single structured prompt.

Define and export `AgentSessionPrompt` interface:
```typescript
interface AgentSessionPrompt {
  fullPrompt: string;              // combined prompt for OpenClaw input
  soulContent: string;             // raw SOUL.md content
  constitutionVerified: boolean;   // true if all INVIOLABLE lines present
  constitutionDirectives: string[]; // extracted INVIOLABLE lines
  taskBrief: string;               // task description + context
  upstreamIntelligence: string | null; // from completed upstream tasks, null if none
}
```

Export `verifyConstitution(soulContent: string, expectedDirectives: string[]): { verified: boolean; missing: string[] }`:
- For each directive in expectedDirectives, check it exists VERBATIM in soulContent (exact string match, trimmed)
- Return verified=true only if ALL directives found; return list of any missing
- If expectedDirectives is empty, return verified=true (pioneer souls may not have constitution yet)
- This directly implements SPAWN-04

Export `buildAgentSessionPrompt(params: BuildParams): AgentSessionPrompt` where BuildParams is:
```typescript
interface BuildParams {
  soulContent: string;
  constitutionDirectives: string[];  // from bot_souls.constitutionDirectives
  taskDescription: string;
  taskId: string;
  requiredTools: string[];
  complexity: TaskComplexity;
  upstreamOutputs: Array<{ taskId: string; summary: string }> | null;  // SPAWN-03: intelligence from completed upstream tasks
}
```

Implementation:
1. Call verifyConstitution — if not verified, log a WARN with the missing directives but do NOT throw (allow execution to proceed; the verification result is recorded in the return value for the spawner to decide)
2. Build `taskBrief` string: "## Task Assignment\n\nTask ID: {taskId}\nComplexity: {complexity}\nRequired Tools: {tools.join(', ')}\n\n{taskDescription}"
3. Build `upstreamIntelligence` string if upstreamOutputs is non-null and non-empty: "## Upstream Intelligence\n\nThe following tasks have completed and produced intelligence relevant to your task:\n\n" + for each: "### Task {taskId}\n{summary}\n\n"
4. Assemble `fullPrompt` in this order (sections separated by ---):
   - SOUL.md content (full, unmodified)
   - "---"
   - Task brief
   - "---"
   - Upstream intelligence (only if available)
   - "---"
   - Footer: "You are bound by the SOUL.md constitution above. Begin executing your assigned task."
5. Return the complete AgentSessionPrompt

Import TaskComplexity from @claw/shared-types.
