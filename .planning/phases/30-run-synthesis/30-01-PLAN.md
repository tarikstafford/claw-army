  <action>
Create `run-synthesis.ts` that exports `generateRunSynthesis(params: RunSynthesisParams): Promise<RingLeaderSynthesis>`.

**RunSynthesisParams interface:**
- `runId: string` — ring_leader_runs.id
- `executionId: string`
- `missionBrief: RingLeaderMissionBrief`
- `runState: RingLeaderRunState` — final snapshot from coordination loop
- `manifests: PopulationManifest[]` — population manifest for soul retrospective
- `coordinationLog: CoordinationLogEntry[]` — from getCoordinationLog(runId)

**Implementation steps:**

1. **Compute event counts** from the coordination log by filtering on event type:
   - `intelligenceRoutingEvents`: count entries where type === 'intelligence_routing'
   - `reallocationEvents`: count entries where type === 'reallocation'
   - `reanchoringEvents`: count entries where type === 'reanchoring'

2. **Compute budget variance** from runState and missionBrief:
   - `budgetVarianceCents = runState.budgetConsumedCents - missionBrief.budgetCapCents`
   - (negative = under budget, positive = over budget)

3. **Build per-task summaries** from `runState.taskStates` crossed with `missionBrief.taskGraph.tasks`:
   - For each task: taskId, completed (status === 'complete'), topPerformingSoulId (first completed agent's soulId looked up from manifests), outputQualitySignal (from taskState), anomalies (filter coordination log for reallocation/reanchoring events referencing this taskId)

4. **Derive pioneer events** from manifests: collect taskIds where `manifest.pioneerFlag === true`.

5. **Derive recommended library writes** from manifests: collect soulIds of all agents assigned to completed tasks where agentClass is 'Artisan' or 'Understudy'. These are candidates for DNA library retention.

6. **LLM call** using Vercel AI SDK `generateText` with `Output.object` and Zod schema for structured output. Use `resolveModel('claude-sonnet-4-6')` (same model as Performance Judge). System prompt instructs the LLM to produce:
   - `objectiveAchieved`: boolean based on task completion rates and anomaly severity
   - `achievementRationale`: 2-3 sentence assessment of whether the objective was met
   - `soulSelectionRetrospective` (SYNTH-02): assess which soul selections worked (completed tasks with no anomalies) and which didn't (failed tasks, reallocation events), referencing agent classes and differentiation scores from manifests
   - `ringLeaderSelfAssessment` (SYNTH-04): evaluate coordination quality — intelligence routing effectiveness, drift management, budget discipline, failure recovery. Reference specific event counts and drift scores.

   The user prompt should include: objective text, task graph summary, per-task completion status, event counts, budget variance, population manifest summary (soul classes, sources, differentiation scores per task), and coordination event highlights (truncated to last 20 events).

7. **Assemble the final RingLeaderSynthesis** by combining LLM outputs with computed fields:
   - `runId`, `objective` from missionBrief
   - `objectiveAchieved`, `achievementRationale`, `soulSelectionRetrospective`, `ringLeaderSelfAssessment` from LLM
   - `taskSummary`, `intelligenceRoutingEvents`, `reallocationEvents`, `reanchoringEvents`, `budgetVarianceCents`, `recommendedLibraryWrites`, `pioneerEvents` from computed values

8. **Persist** the synthesis to `ring_leader_runs.synthesis` via `db.update(ringLeaderRuns).set({ synthesis, status: 'completed', completedAt: new Date(), updatedAt: new Date() }).where(eq(ringLeaderRuns.id, runId))`.

**Error handling:** If the LLM call fails, fall back to a synthesis with `objectiveAchieved = false`, a rationale noting synthesis generation failure, empty strings for retrospective and self-assessment. Still persist and transition to 'completed'. Log the error at WARN level.

**Constants:**
- `SYNTHESIS_MODEL = process.env.SYNTHESIS_MODEL ?? 'claude-sonnet-4-6'`
- `MAX_COORDINATION_LOG_EVENTS = 20` (truncate log for prompt size)
- `MAX_MANIFEST_SUMMARY_CHARS = 4000` (cap manifest text in prompt)

Use `import type` for all type-only imports. Follow existing patterns from `assemble-population.ts` and `drift-detector.ts` for LLM call structure.
