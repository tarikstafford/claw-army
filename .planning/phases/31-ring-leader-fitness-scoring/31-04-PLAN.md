  <action>
Create `ring-leader-class-progression.ts` that exports `evaluateRingLeaderPromotion()`.

**Important context:** This is a SEPARATE promotion system from the bot agent class-machine.ts. Bot agents are promoted via council verdicts (God Layer worker). Ring Leaders are promoted based on accumulated fitness scores across multiple runs. The Ring Leader's soulId links to its entry in agent_classes (same table, different evaluation path).

**Params:**
- soulId: string (Ring Leader's soul ID — from ring_leader_runs.soulId)
- ringLeaderRunId: string (the just-completed run)
- compositeScore: number (from the just-computed fitness)

**Return type (RingLeaderPromotionResult):**
```typescript
export interface RingLeaderPromotionResult {
  promoted: boolean;
  previousClass: 'Novice' | 'Understudy' | 'Artisan';
  newClass: 'Novice' | 'Understudy' | 'Artisan';
  reason: string;
  runCount: number;
  qualifyingRunCount?: number;  // only for Understudy->Artisan
}
```

**Implementation:**

1. **Early exit if soulId is null:** Ring Leader runs without a soul (early phases or test runs) cannot be promoted. Return `{ promoted: false, previousClass: 'Novice', newClass: 'Novice', reason: 'No soul assigned', runCount: 0 }`.

2. **Fetch current class from agent_classes table:**
   Query `agent_classes` where soulId matches and taskCategory = 'ring_leader' (Ring Leader uses a special task category). If no row exists, insert a new Novice entry:
   ```typescript
   // Use db.select from agentClasses where botId = soulId and taskCategory = 'ring_leader'
   // Note: agent_classes uses botId column (historically), but for Ring Leaders we store soulId in botId
   ```
   Extract currentClass from the row.

3. **Count total completed runs for this soul:**
   Query `ring_leader_runs` where soulId matches AND status = 'completed'. Count = runCount.

4. **Evaluate Novice -> Understudy (FIT-05):**
   Import RING_LEADER_PROMOTION_THRESHOLDS from @claw/shared-types.
   ```
   const { minRuns, minConfidence } = RING_LEADER_PROMOTION_THRESHOLDS.noviceToUnderstudy;
   // minRuns = 4, minConfidence = 0.68
   ```
   Check: `runCount >= minRuns && compositeScore >= minConfidence`
   If both pass AND currentClass === 'Novice': promote.

5. **Evaluate Understudy -> Artisan (FIT-05):**
   ```
   const { minRuns, minConfidence, minSoulSelectionScore, qualifyingRunsRequired } = RING_LEADER_PROMOTION_THRESHOLDS.understudyToArtisan;
   // minRuns = 9, minConfidence = 0.85, minSoulSelectionScore = 0.75, qualifyingRunsRequired = 6
   ```
   - Check runCount >= minRuns (9)
   - Check compositeScore >= minConfidence (0.85)
   - Count "qualifying runs": query ring_leader_fitness joined with ring_leader_runs (where soulId matches), filter where the soul_selection_score average (computed as average of the 5 dimensions from the JSONB) >= minSoulSelectionScore (0.75). Count how many runs meet this criterion = qualifyingRunCount.
   - All three must pass: `runCount >= 9 && compositeScore >= 0.85 && qualifyingRunCount >= 6`
   If all pass AND currentClass === 'Understudy': promote.

6. **On promotion:**
   Update agent_classes row: set currentClass to new class, update updatedAt.
   Log: `[ring-leader-class] Promoted soulId={soulId} from {previousClass} to {newClass} after {runCount} runs`

7. **On no promotion:**
   Log: `[ring-leader-class] No promotion for soulId={soulId} class={currentClass} runCount={runCount} composite={compositeScore}`
   Return with promoted=false and reason explaining which threshold was not met.

**Import from @claw/db:** db, ringLeaderRuns, ringLeaderFitness, agentClasses.
**Import from @claw/shared-types:** RING_LEADER_PROMOTION_THRESHOLDS.
**Import from drizzle-orm:** eq, and, sql, count.

Do NOT import from class-machine.ts — Ring Leader class progression is independent from bot agent class progression.
