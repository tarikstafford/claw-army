<objective>
Wire the Tool Gateway proxy to enforce per-execution domain filtering. When a proxy request includes an `X-Execution-Id` header, look up `allowedDomains` from the executions table and apply that allowlist instead of the global `PROXY_DOMAIN_ALLOWLIST`. When the header is absent or the execution has null allowedDomains, fall back to the global allowlist.

Purpose: Per-execution domain filtering gives each execution a scoped security boundary. Different executions can restrict bot access to different domain sets without changing the global gateway config.

Output: New domain-allowlist service module, updated proxy handlers (both CONNECT and HTTP forward).
</objective>

Implementation:
```typescript
import { db, executions } from '@claw/db';
import { eq } from 'drizzle-orm';

/**
 * In-memory TTL cache for per-execution allowed domains.
 * allowedDomains is set at execution creation and never changes,
 * so 60s TTL is a safety net, not a freshness requirement.
 */
const cache = new Map<string, { domains: string[] | null; expiresAt: number }>();
const CACHE_TTL_MS = 60_000;

/**
 * Look up the per-execution allowedDomains from the executions table.
 * Returns string[] if the execution has specific domains, null if not set.
 * Caller should fall back to global allowlist when null is returned.
 */
export async function getExecutionAllowedDomains(
  executionId: string,
): Promise<string[] | null> {
  const now = Date.now();
  const cached = cache.get(executionId);
  if (cached && cached.expiresAt > now) {
    return cached.domains;
  }

  const rows = await db
    .select({ allowedDomains: executions.allowedDomains })
    .from(executions)
    .where(eq(executions.id, executionId));

  const domains = rows[0]?.allowedDomains ?? null;
  cache.set(executionId, { domains, expiresAt: now + CACHE_TTL_MS });
  return domains;
}
```

Design decisions:
- **In-memory Map, not Redis**: allowedDomains is write-once; Redis adds unnecessary network latency for this read pattern.
- **null = "use global fallback"**: Semantically different from empty array `[]` (which means "allow all"). The caller interprets null as "no per-execution override."
- **Fail-open on missing execution**: If the executionId is not found, returns null. The proxy layer is not the primary auth gate (JWT handles that). Using the global fallback for unknown executions is safe.
