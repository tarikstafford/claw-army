Wire the Tool Gateway's proxy handlers to enforce per-execution domain filtering by reading `allowedDomains` from the execution record. When an execution has `allowedDomains` set, only those domains are permitted through CONNECT/HTTP proxy; when null, the global `PROXY_DOMAIN_ALLOWLIST` env var applies.

Purpose: Per-execution domain filtering gives each execution a scoped security boundary. Different executions can have different domain access profiles without changing the global gateway config.

Output: New domain-allowlist service module, updated proxy handlers.

  <action>
Create a new file `services/tool-gateway/src/services/domain-allowlist.ts` that exports a `getExecutionAllowedDomains(executionId: string)` function.

Implementation:
```typescript
import { db, executions } from '@claw/db';
import { eq } from 'drizzle-orm';

/**
 * In-memory TTL cache for per-execution allowed domains.
 * Avoids a DB query on every proxy request. Cache entry expires after 60 seconds.
 * This is acceptable because allowedDomains is set at execution creation and never changes.
 * The short TTL is a safety net, not a freshness requirement.
 */
const cache = new Map<string, { domains: string[] | null; expiresAt: number }>();
const CACHE_TTL_MS = 60_000;

/**
 * Look up the per-execution allowedDomains from the executions table.
 * Returns string[] if the execution has specific domains, or null if not set
 * (caller should fall back to global allowlist).
 * Returns null if execution not found (fail-open for proxy; tool-invoke has its own auth).
 */
export async function getExecutionAllowedDomains(
  executionId: string,
): Promise<string[] | null> {
  const now = Date.now();
  const cached = cache.get(executionId);
  if (cached && cached.expiresAt > now) {
    return cached.domains;
  }

  const rows = await db
    .select({ allowedDomains: executions.allowedDomains })
    .from(executions)
    .where(eq(executions.id, executionId));

  const domains = rows[0]?.allowedDomains ?? null;
  cache.set(executionId, { domains, expiresAt: now + CACHE_TTL_MS });
  return domains;
}
```

Key design decisions:
- **TTL cache (60s)**: allowedDomains is write-once at execution creation, so staleness is not a concern. The cache prevents a DB round-trip on every CONNECT/HTTP proxy request.
- **null return = use global fallback**: The proxy handler interprets null as "no per-execution override, use PROXY_DOMAIN_ALLOWLIST".
- **Fail-open on missing execution**: The proxy layer is not the primary auth gate (JWT auth in tool-invoke handles that). If the execution is missing, allow the global allowlist to decide.

2. **Refactor `isDomainAllowed`** to accept an optional per-execution domain list:
   ```typescript
   function isDomainAllowed(hostname: string, perExecutionDomains?: string[] | null): boolean {
     // Per-execution domains take precedence when set
     const allowlist = perExecutionDomains ?? PROXY_DOMAIN_ALLOWLIST;
     if (allowlist.length === 0) return true; // allow all if unconfigured
     return allowlist.some(
       (allowed) => hostname === allowed || hostname.endsWith(`.${allowed}`),
     );
   }
   ```

3. **Extract executionId from proxy requests.** Bot VMs send traffic through `HTTP_PROXY` which means the proxy sees the source IP but NOT the executionId directly. Two approaches to resolve executionId:

   **Approach: Use a custom Proxy-Authorization or X-Execution-Id header.**
   The GCE bot launcher already configures `HTTP_PROXY` on the VM. Modify the approach to:
   - Accept an `X-Execution-Id` header on proxy requests (CONNECT and HTTP forward).
   - If the header is missing, fall back to the global `PROXY_DOMAIN_ALLOWLIST` (backward compatible).

   In `handleConnect`:
   ```typescript
   const executionId = req.headers['x-execution-id'] as string | undefined;
   let perExecutionDomains: string[] | null = null;
   if (executionId) {
     try {
       perExecutionDomains = await getExecutionAllowedDomains(executionId);
     } catch (err) {
       console.error(`[proxy/connect] ${requestId} Failed to fetch execution domains (using global):`, err);
     }
   }

   if (!isDomainAllowed(hostname, perExecutionDomains)) {
     // ... existing block logic
   }
   ```

   **Important:** `handleConnect` must become `async` to await the domain lookup. Update the signature:
   ```typescript
   async function handleConnect(
     req: http.IncomingMessage,
     socket: net.Socket,
     head: Buffer,
   ): Promise<void> {
   ```
   And update the server.on('connect') registration to handle the promise:
   ```typescript
   fastify.server.on('connect', (req, socket, head) => {
     handleConnect(req, socket, head).catch((err) => {
       console.error('[proxy/connect] Unhandled error:', err);
       socket.destroy();
     });
   });
   ```

   Similarly make it async, extract `x-execution-id` header, call `getExecutionAllowedDomains`, and pass the result to `isDomainAllowed`.

4. **Log which allowlist was used** in the console.log for each request (helpful for debugging):
