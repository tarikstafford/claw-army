**1. Create `services/execution-service/src/routes/souls.ts`:**

Create a Fastify route plugin `soulsRoutes` with `GET /` endpoint. Follow the exact pattern from `objectives.ts`.

Query parameters (all optional via TypeBox):
- `category` (string) — filter by `taskCategory`
- `agentClass` (string) — filter by agent class (requires join)
- `limit` (integer, min 1, max 100, default 50)
- `offset` (integer, min 0, default 0)

Query logic:
- Select from `botSouls`: id, taskCategory, generation, isArchetype, archetypeName, createdAt
- Do NOT select `soulContent` (large text field, omit for list performance)
- For agent class: do a LEFT JOIN on `agentClasses` via `botId` where `agentClasses.taskCategory = botSouls.taskCategory`. For archetypes (botId is null), agent class will be null — this is expected.
- IMPORTANT: Use a subquery or lateral approach to get the agent class for each soul. Since `agentClasses` has (botId, taskCategory) unique constraint, the join is 1:1 when botId and taskCategory match.
- If `agentClass` filter is provided, add WHERE on the joined `currentClass`
- If `category` filter is provided, add WHERE on `botSouls.taskCategory`
- Order by `createdAt` DESC
- Use `.limit(limit).offset(offset)` for pagination
- Also run a count query for total
- Use `generation` as the fitness proxy (higher = more evolved). For `compositeScore`, do a best-effort LEFT JOIN to `bots` table via `botSouls.botId` to get `bots.compositeScore`. If botId is null (archetype), compositeScore will be null.
- Also add a second endpoint: `GET /categories` that returns `SELECT DISTINCT task_category FROM bot_souls WHERE task_category IS NOT NULL ORDER BY task_category` — this feeds the filter chip UI.

Response schema:
```typescript
{
  souls: Array<{
    id: string;
    taskCategory: string | null;
    generation: number;
    isArchetype: boolean;
    archetypeName: string | null;
    agentClass: 'Novice' | 'Understudy' | 'Artisan' | 'Retired' | null;
    compositeScore: number | null;
    createdAt: string;
  }>;
  total: number;
  hasMore: boolean;
}
```

Categories response: `{ categories: string[] }`

No auth guards (read-only GET, consistent with existing pattern).

// Phase 39 — Soul Library (SOUL-01)

export async function getSoulLibrary(
  params: { category?: string; agentClass?: string; limit?: number; offset?: number } = {}
): Promise<SoulLibraryResponse> {
  const query = new URLSearchParams();
  if (params.category) query.set('category', params.category);
  if (params.agentClass) query.set('agentClass', params.agentClass);
  if (params.limit != null) query.set('limit', String(params.limit));
  if (params.offset != null) query.set('offset', String(params.offset));
  const qs = query.toString();
  return apiFetch(`${BASE}/souls${qs ? `?${qs}` : ''}`);
}

export async function getSoulCategories(): Promise<SoulCategoriesResponse> {
  return apiFetch(`${BASE}/souls/categories`);
}

// Phase 39 — Category Benchmarks (SOUL-04)

export async function getCategoryBenchmarks(): Promise<CategoryBenchmarksResponse> {
  return apiFetch(`${BASE}/category-benchmarks`);
}
