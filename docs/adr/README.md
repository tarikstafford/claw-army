## Template

New ADRs should follow this structure:

```markdown
# ADR-NNNN: Title

**Status:** Proposed | Accepted | Deprecated | Superseded
**Date:** YYYY-MM-DD
**Context:** milestone/phase reference

## Decision
What was decided.

## Context
Why the decision was needed and what alternatives were considered.

## Rationale
Why this option was chosen.

## Consequences
What changes as a result.
```
